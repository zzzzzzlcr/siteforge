# 缺陷单（2026-10-12）：注册那 17 步**整组被跳过** —— 「没读到正文」有两副面孔，合并只认了一副

**一句话**：探索期把「同一页被判成几个状态」并成一个时，对「判据钉不出来」的那一眼只会
**往前并**；可那一页**读到了正文**（只是那段是跨元素拼的）、在它名下做的步就发生在**它这一屏上** ——
往前并等于**把下一屏的门交给了一步「制造那扇门」的动作**：组里第一步是「点 Create account」，
而门 =「注册屏正文」⇒ **门永远不成立** ⇒ 那 17 步整组跳过，页面从没走到注册屏。

## 三、根因

`agent/browser_agent.py::_merge_one_page_states` 的第一支（「**没读到正文**的那一眼不是一页」）：

```python
prev = pages[here - 1] if here > 0 else None
if prev is not None and when_holds(prev.get("when") or {}, pg.get("model") or {}):
    target = prev                     # ← 上一页的门在这一眼里还成立 ⇒ 并回去（2026-10-12 那条补丁）
else:
    target = next((q for q in pages[here + 1:] if q in readable), None) or …   # ← 否则往前并
```

「没读到正文」其实有**两副面孔**，那一支只认了第一副：

| | 什么形状 | 该往哪并 |
|---|---|---|
| ① | 那一眼**一个字都没读到**（观测撞上加载中的页面） | **往前**（它不是一页，是接着变成的那一页的加载态）✓ 老规矩对 |
| ② | 那一眼**读到了正文、只是钉不出单元素判据**（正文头是跨元素拼的 / 被截断） | **往回**（它是一页；在它名下做的步就发生在它这一屏上）✗ 老规矩往前并 |

本单是②：`prev`（`auth`）的门是**页脚**那句，而那一屏的正文头里根本没有页脚（真站那一趟正文头
被截在页脚之前）⇒ 「上一页的门还成立吗」这一问**问不出答案** ⇒ 落到「往前并」⇒ 循环守卫。

⚠️ 与 2026-10-12 那条补丁（`job-e7906a6c65d0`）是**同一个死法、不同的触发面**：那条治的是
「门能在这一眼里验出来」的情形；这一单的门**在正文头之外**，验不出来。

## 四、已修（2026-10-12）

`_merge_one_page_states` 里补第三支（判据全是**量得到的**）：

```python
elif _read_something_but_no_pinnable_gate(prev, pg, url):
    target = prev
```

`_read_something_but_no_pinnable_gate` 三条同时成立才算：
① 这一眼**读到了正文**（`model.page_text` 非空 —— 与「一个字没读到」分得开）；
② `prev` 在**同一个稳定地址**上（同一屏家族；跨地址是两页，§1 那一验照旧管）；
③ `prev` **自己有一段钉得住的判据**（只有 URL 的那条不许当门 —— 那等于这一组在任何一屏上都成立）。

只补这一支 ⇒ 「一个字都没读到」那条路**一个字节没变**（负控钉在
`test_a_loading_look_is_still_merged_forward`），2026-10-12 那条补丁的行为也没变
（`test_a_gate_that_could_not_be_pinned_goes_back_to_the_screen_it_happened_on`）。
