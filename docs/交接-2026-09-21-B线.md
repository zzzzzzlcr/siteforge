## 3. ★ 实测事实（可以直接当判据，**用之前不用再验**）

### `GET /api/quest/formScript?site=<键>`

- **公开**（不带任何头也回 200）⇒ `need_token=False`
- 回 `{site, requested_site, type, version, sha256, source}`
- `type` 是 **`py` 或 `json`** —— **一个口两种**。后端判据是 `scriptKind()`：
  `script_source` 非空 ⇒ py；否则 `steps` 解得出非空数组 ⇒ json；都没有 ⇒ `status:404 script not found`
- ⚠️ **`type: json` 不是「这个站的脚本是空的」**，是「**这个站跑的是配置**」——
  两件事处置完全不同（前者该走 `form_config`，后者才是「该补一份脚本」）
- `source` 是**逐字节**的（后端原话「首尾换行是源码的一部分」，而且写口拿 sha256 当指纹）
  ⇒ 任何 `strip()` 都算把源码改坏了，**而且是静默的**

### `&type=debug`（用户 2026-09-21 新加的）

```
site=compareinsulation.io/article-1-c                → {"status":404,"msg":"script not found","data":[]}
site=compareinsulation.io/article-1-c&type=debug     → {"status":200,"msg":"ok","data":{…}}
site=compareinsulation.io                            → 404
site=compareinsulation.io&type=debug                 → 404
```

debug 的 `data` 形状：

```json
{"site": "compareinsulation.io/article-1-c",
 "requested_site": "compareinsulation.io/article-1-c",
 "type": "json",
 "steps": { …那份配置… },
 "status": 0}
```

- **debug 绕过 `where('status', 1)`** ⇒ 停用的也拿得到
- **debug 多给一格 `status`**（0 = 停用）
- ⚠️ **json 支的载荷在 `steps` 那一格**，py 支在 `source` —— **两种支的键不一样**

### 站点匹配规则【转述的·用户 2026-09-21】

> 「存的 site 必须是**请求值的 host+path 前缀**」

推论（实测印证过）：
- 请求 `callyourdate.com/land/sp/519015a5`，存的 `callyourdate.com` ⇒ **匹配**（存的是前缀）
- 请求裸 `compareinsulation.io`，存的 `compareinsulation.io/article-1-c` ⇒ **不匹配**（存的不比请求短）
- **大小写敏感**；产物短名（如 `callyourdate`）它**不认**

### `has_script` 那一格的语义

后端 `scriptKind() !== null` ⇒ `has_script` 为真 —— 即 **py 或 json 都算「有脚本」**。
（见 §6 那处说假话的地方。）
