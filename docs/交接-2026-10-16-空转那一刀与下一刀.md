## ② 落了什么（判据 / 处置 / 停因 / 可见）

- **判据** `graph._same_as_the_tested_one`：只比**产物真正读的那几格**（`states` / `fills` /
  形态 / 成功判据）。白捡的三样：dict 的 `==` **不看键序**、`PROVENANCE` 的时间戳不在里面、
  **循环型那一支不读 `states` 就不比它**（不读的东西改了不算改）。
- **处置**：一样 ⇒ 照 `_patch_draft` 那条先例把「一处都没改」走 `feedback["violations"]`
  **回灌再问一次**（`WRITE_ATTEMPTS = 2`）；还是一样 ⇒ **停**。停时**不渲、不 lint、不跑自测**，
  往下走 / 留给人拿的**还是被测的那一版**。每一回都从同一份底稿重新出发（拿被钉回去过的那份当底
  = 把「退回」当成模型的改动）。

  那条的出路是**重探**，这条的出路是**给一句话**或**接上那根线** —— 处置不一样，不能并成一个数
  （与 `END_WINDOW_GONE` / `END_EXPLORE_UNFINISHED` 同一条规矩）。`fam_report.FAMILY_SAY` 加了一行
  「改稿那双手一处都没改」；`CAP_END_REASONS` **没动**（它不是触顶，是「没进展」）。
- **闸上那句话**把两种「没改」分开说：**没接那双手**（`Deps.write` 还是默认那个恒等翻译器 /
