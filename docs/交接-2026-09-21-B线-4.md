## 2. 那条路现在长什么样

```
面板「开一趟」(mode=fix)
   ↓
_stage_fix_source ── 后端 formScript 读旧脚本 → 落 <out_dir>/<短名>.before.py
   ↓
intake ── fix.from_py() 读得出 STATES/FILLS？
   ├─ 读得出 ⇒ 【模板形】今天那条路，**逐字节没动**
   ├─ 读不出、但形状是老写法（fix.shape_of 走 ast 量的四个记号）⇒ 【老写法】fix_style="legacy"
   └─ 都不是 ⇒ 停下，逐条说缺什么（人话）
   ↓（老写法）
explore ── **不探索**（不开浏览器），只在闸上说清「拿的是线上那一份、走补丁那条路」
   ↓
draft ── deps.patch_source(旧源码, feedback) → extract_source → **check_patch 过闸**
          （没过闸 ⇒ 停下并**逐条**摆出原因，一份都不落盘、不往下走）
   ↓
lint ── 照旧（手拼 JS 那条）
   ↓
selftest ── legacy=True：argv 不给那三个开关（它们不认），
            改由 SITEFORGE_TRACE / SITEFORGE_NO_REPORT 从**运行时**取证据；
            判据**一个字不改**（退出码 0 + 有证据行）；放慢那一遍记 not_needed
   ↓
deliver ── 落 <out_dir>/<短名>.py（**就是那一版补丁，一字未改**，不加 PROVENANCE）
```

**形状那四个记号**（`fix.shape_of`，全是量的）：`from common import … report_url`（且真调）、
`main()` 里认出生产那四个开关、`sys.exit(0 if … else 1)`、`ast.parse` 过。
⚠️ **类名叫什么不是判据**（`LpaFiller` / `_CaptchaClient` 都可能是老写法）。

**补丁那五条闸**（`fix.check_patch`）：不是空文件 · `ast.parse` 过 · 四个开关一个不少 ·
成功判据那一行还在 · 还 import 且真调 `report_url`。

### 3.6 换了形状（甲）之后的实测（同一天继续跑）

用户拍板：**甲 —— 只交改动的那几段（diff），我们机械套上去**。落法：
`fix.apply_diff()`（**严格**：diff 里每一行 `-`/上下文必须与旧源码逐字一致，对不上就抛、
一个字都不改）+ `fix.source_from_reply()`（先剥围栏：有 `@@` 走套用，整份 py 照收，
都不是就红）+ `_patch_draft` **最多试两次**（把「哪一行对不上」逐条回灌再补一次）。

**真跑的量（同一站、同一条提示词、同一份旧脚本）**：

| 试 | 模型 | 预算 | 结果 |
|---|---|---|---|
| A | `deepseek-v4-flash`（思考型） | 12000 / 32000 / 64000 | **全部**被思考吃满、`content` 空（最慢一次 276 秒） |
| B | **`deepseek-chat`**（非思考） | 8000 | **4 秒**、583 token、交回一段**小 diff** |
| C | `deepseek-chat` | — | 那一版 diff 的**上下文抄错了**（拿「第 2 行」去对，实际是另一行）⇒ 套用**严格拒** |
| D | `deepseek-chat` + 提示词把旧源码**带行号**给 | — | **成了**：12 秒走完 explore → draft → 套用 → 过闸 → lint，**停在自测那一关** |
| E | 同上（重跑，采样不同） | — | 又撞在「抄错上下文」上（同一处拒、一个字没改） |

⇒ **两条结论**：
1. **换模型是承重的**：`SPIKE_MODEL=deepseek-chat`（非思考）—— 思考型在这个活上是 0 产出。
   ⚠️ 服务现在**就是这么起的**（见 §5）。
2. **甲能成但不稳**：`deepseek-chat` 抄上下文时不时抄错（严格套用当场拒，所以**不会静默改错**）。
   手上有三根更稳的杠杆（**要用户/控制者定一根或几根**）：
   - **重试次数**加一点（答一次 4 秒 ⇒ 便宜；现在是 2 次）；
   - 换成「**行号 + 短锚点**」的形状（只回「第 N–M 行换成 …」+ 那一行开头几个字，
     我们按行号切、拿锚点核对）—— **不用它抄原文**，抄错这个失败源就没了；
   - 先让它只出「哪里错了、该改什么」（小输出），改动由更小的第二次调用落。

### 3.6b 换成「**行号 + 短锚点**」之后（用户挑的那根杠杆）

形状：模型回 `<<<REPLACE <起行>-<止行> <锚点>` … `>>>`（`fix.apply_edits`）——
**不用它抄原文**，行号与锚点任一不符就整份退回、一个字都不改。

**真跑两趟（同站同提示词）**：① 14 秒、② 8 秒 —— **两趟都套上并走到自测那一关**（对比：diff 那个形状两次里撞一次）。
⇒ **形状这一层稳了。**

**但内容不行**（闸上那格 diff 抓出来的，人一眼可见）：

| 趟 | 它改了什么 |
|---|---|
| ① | 把一行注释**少了一个空格**（纯缩进变动，等于没修） |
| ② | **一处都没改**（闸上写「与旧脚本逐字一样」） |

⇒ 根因换了：**不是套用形状，是模型手上没有真证据**。它只有「失败那一行 + 旧脚本」，
没有失败那一步的**页面/日志**（这一单最后一行报的是 `max_steps`：脚本走满 40 步没到 thank-you）——
所以它编不出对的补丁（连「改哪儿」都指不准）。
⇒ 下一步的岔路（**要用户/控制者定**）：
- **（丙）先让它出「错在哪里、该改什么」**（拿失败证据 + 逐段代码问，小输出），确认了再落改动；
- 或者**把真证据喂给它**：失败那一步的页面事实（`observe` 一屏 / 日志尾巴）——
  那要接浏览器（也就是 `explore` 那一层本来就在做的事）。
⚠️ 无论哪条，**闸上那格 diff 都要留着**：它刚刚证明了自己的价值（人一眼看出「只动了一个空格」）。

### 3.7 顺手补的三件（都是真跑逼出来的）

- **空回话带账上屏**：`fix.patch_from_rounds()` —— 说清 `finish_reason` / 思考 token / 预算，
  不再把「我们预算不够」记成「模型没给东西」。
- **闸上看得见「它改了什么」**：`graph._patch_diff()` 把这一版的 unified diff 摆进
  **自测 / 交付**那两道闸的事实里（截断并说清截断）。⚠️ 为什么非有不可：老写法那一版是
  模型整段改出来的，而人是在**自测那道闸上**按「继续」放它去跑真页面的 ——
  那一下不该按在一句概括上。
- ⚠️ 一处**只有真跑才撞得到**的形状：重试回灌的是**字符串**，而 `lint` 那一侧给的是
  **字典** ⇒ 只按字典读，第二次就 `AttributeError`。现在两形状都认（`fix.violations_for_prompt`）。
下一次要动的就是**这个形状**，三条路（**要用户/控制者定**）：

- **（甲）只交改动的那几段**：让模型回一段 `patch -p0` 能用的 diff（或「第 N–M 行换成 …」），
  由我们这边**机械地套上去**，再照旧过闸 + lint + 自测。输出量小一大截 ⇒ 思考也不会被撑爆。
- **（乙）换模型**：`llm.py` 认 `SPIKE_MODEL`（默认 `deepseek-v4-flash`）—— 换一个思考克制的。
- **（丙）先让它只出「哪里错了、该改什么」**（小输出、便宜），改动由更小的第二次调用落。

⚠️ **自测那一关没跑**（没动真页面、没提交），窗口已经关掉。
⚠️ 这一趟也顺手验到了两条好的：面板那条路**真能走到 draft**（intake 认老写法 ✓、
不探索 ✓、闸上的话就是老写法那句 ✓）、以及**空回话现在会带账上屏**（②）。
