# 缺陷单（2026-11-13）：同一页被尾斜杠拆成两页 —— 「判据分不开页」⇒ 一份 py 都不出

**一句话**：站点把 `/products?source=nav` 写成 `/products/?source=nav`（多一个尾斜杠），
两次观测被当成**两页**；先那一眼还在加载（正文空，判据只剩地址），后一眼读到了正文。
`_gates_that_hold_elsewhere` 于是报「products 这组的判据在另一页上也成立」⇒ `draft_failed`。
差别只是**尾斜杠**，而四处「同一页」的比较都是逐字比 `_stable_url` ⇒ 永远对不上。

---

## 一、现场

| | |
|---|---|
| job | `job-eb9e6bf071f1` |
| 站点 | `accounts.theatlantic.com/products`（`/products?source=nav` → `/products/?source=nav`） |
| 读数 | 探路 19 步、`reached_success`、151 秒；但 `end_reason=draft_failed`、`delivered=false` |
| 症状原话 | 「「products」这一组**只有地址**当门 …… 这一趟账本里的判据**分不开页**」 |

## 二、量到的证据

账本（`runtime/explore/job-eb9e6bf071f1/attempt-1.jsonl`）：

```
步 11 observe  url=https://accounts.theatlantic.com/products?source=nav   page_text=""
步 16 observe  url=https://accounts.theatlantic.com/products/?source=nav  读到正文
```

两次的 `_stable_url`：

```
https://accounts.theatlantic.com/products     ← 不带尾斜杠
https://accounts.theatlantic.com/products/    ← 带尾斜杠
```

**同一页**，两串只差尾斜杠 ⇒

- `_merge_one_page_states` ① 找不到「同一地址上读到正文的那一眼」⇒ 空门活下来；
- `_gates_that_hold_elsewhere` 的同址跳过不成立 ⇒ 报「别的页上也成立」；
- `_repair_ambiguous_whens` 把同一页的兄弟观测当「别的页」避让。

## 三、根因

四处「是不是同一页」都是 `_stable_url(a) == _stable_url(b)` **逐字比**。站点多一个 /
少一个尾斜杠，答案就从「同一页」变成「两页」。

## 四、修法

新增 `browser_agent._same_stable_url`，只在**比较处**用（判据里的字符串一个字不动）：

- 两个裸地址（去 query/fragment/尾斜杠）相同 ⇒ 同一页；
- 否则退到 `_stable_url` 相同（轮换变体），但**短的那条不是长那条的路径前缀**
  （`/funnel` 与 `/funnel/step2` 是上级/子页，不许认成同一页）；
- `/walk-in-showers/cr640` 与 `…/gt1791-1` 照旧算同一页（真轮换）。

替换：`_gates_that_hold_elsewhere` 的同址跳过、`_merge_one_page_states` 的 readable /
相邻并组、`_read_something_but_no_pinnable_gate`、`_repair_ambiguous_whens` 的
「别的页」候选。

## 五、用例

`tests/test_browser_agent.py::test_the_same_page_with_a_trailing_slash_difference_is_one_page`
（先红后绿）。三条对照照旧绿：

- `test_a_bare_url_gate_is_not_evidence_that_two_screens_are_one_page`（加载中并往前）；
- `test_two_pages_that_share_their_text_are_still_two_states`（`/funnel` 与 `/funnel/step2`
  仍是两页）；
- `test_a_round_trip_is_never_flattened_into_one_group`（往返不许压平）。
