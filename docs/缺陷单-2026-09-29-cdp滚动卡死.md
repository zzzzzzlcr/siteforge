# 缺陷单（2026-09-29）：`cdp scroll` 在「元素离视口很远」时跑到超时被杀

**给谁**：cdp 那条线（`/company/cdpcli`，`internal/client.go` 的滚动一族）
**严重度**：高（**整单挂**，而且失败现场只剩一句 `TimeoutExpired`，什么都判不出来）
**状态**：cdp 侧未修；我们这边只做了**止血**（见文末）

> **⚠️ 同族第二张单（同一段代码、另一个机理，后果更坏）**：
> `缺陷单-2026-09-29-cdp选中隐藏重复件.md` —— `__cdpQ` 取的是**文档顺序第一个匹配**、不看可见性。
> afrotech 页面上有两个同名按钮，第一个是 `[hidden]` 里的 0×0 重复件 ⇒ 比例判据 `0/0 = NaN` 恒假、

## 根因（代码级）

```
cmd/scroll.go:48      runScroll → ScrollToElement(选择器)
internal/client.go:1100  ScrollToElement：for i := 0; i < 20; i++ {
                             每轮之间 sleep 200–600ms
                             ScrollTouch(选择器)      // :946
                             if IsElementVisible(选择器) { break }   // :864
                         }
internal/client.go:886   ScrollIntoView（精确的 el.scrollIntoView({block:'center'})）
                         ← 写在最后，只有前面 20 轮跑完才轮到它
```

三个乘数叠起来：

1. **一轮大约只走一屏**（实测 20 轮走完 17,166px ≈ 858px/轮），而这次要 **21 屏** ⇒ 20 轮的上限**刚好差一点**，最后是 `ScrollIntoView` 那一击把它送到位的；
2. **每轮 15 个 `touchMove`**（`ScrollTouch` 里 `sampleBezier(..., 15)`），**每个都是一次到远端窗口的 CDP 往返**（窗口在别的机器上）⇒ 一轮 1–3 秒；
3. **可见判据是「至少 80% 落在视口内」**（`IsElementVisible`：`visibleArea/totalArea >= 0.8`）。

⇒ 20 轮 = **25 秒（快链）～ 40 秒（慢链）**，而调用方（`forms/common.py` 的 `subprocess.run(timeout=…)`）那条线压在 30 秒上。
**这不是站点的问题，是「距离 × 往返延迟」的时间题。**

## 影响面：不只是 `scroll` 这一步

`ScrollToElement` 是**所有会动到元素的命令**的公共前置：

| 调用者 | 位置 |
|---|---|
| `ClickElement` | `internal/client.go:1156` |
| `form` / `check` / `select` | `internal/form.go:340 / 474 / 805` |
| `cdp scroll` | `cmd/scroll.go:48` |

⇒ 产物里删掉「滚进视口」那一步**没有用**（下一句 `form` 照样卡），修一处才能全局生效。

## 建议的修法（按性价比）

1. **按距离分流**（真修，改一个函数）：先量元素中心离视口**几屏**——**>2 屏就直接 `ScrollIntoView`**（一次调用、毫秒级），再补 1–2 轮拟人滑动"抹平"；≤2 屏维持现在的拟人循环。21 屏那单会从 25 秒变成 <2 秒。
2. **循环的界要跟距离走**：轮数按 `ceil(几屏)+2` 算（别固定 20），并给**总时长上限**（例如 8 秒）——超了就落到精确那一下，而不是继续磨。
3. **失败要说人话**：把「滚了 N 次、元素只露 X%、离几屏、滑动起点坐标上站着的是谁」写进错误/回执。现在超时那一刻**一个字段都没有**（和交接文档 §4「失败现场是抽样的」同一个病）。
4. **顺带看一眼 `ScrollTouch` 的起点**：`startY = vpHeight - randOffsetY` = **贴底那条边**——贴底广告条/同意条在的时候，触摸会被那一层吃掉（本次**没有**证实：afrotech 的 `.htlad-adhesion` 实测高度 0；但那是最容易被占的位置，起点往上挪 15–20% 是便宜的保险）。
