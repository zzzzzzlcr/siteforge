## 出错先看哪

- trace 里 **「X 一直盖着 Y」** ⇒ 先看 #9（是不是自己的壳），再看 #11（真遮挡）。
- trace 里 **「不当遮挡点掉」/「已经标成流程本身」** ⇒ #5 #6 #8；先确认**点名的是哪一颗**。
- **「没找到 close modal button」** 且后面页面乱 ⇒ #4（别重定位）。
- **`lint_cap` / `judge-fragile-no-basis`** 指向 `scroll` ⇒ #10。
- **点了 `aria-label=close` 没反应** ⇒ #2 #3（隐藏副本 / 视口外）。

## 遇到新形状怎么加

1. **真站复现**：拿到 `job-*`、trace 行、页面那几颗元素的 id/class/aria 原话。
2. **窄口径**：能写成「同时满足 A 与 B」就别写成「带某个词就放行」；默认必须是**拦**。
3. **钉两道**：
   - JS 本体：`tests/popup_probe_driver.js` + `tests/test_popup_hooks_js.py`（假 DOM 真跑）；
   - 产物行为：`tests/test_template.py`（替身 `common`，断言真发出去的动作 / trace 行）。
   - **每条放宽都要有负控**（否则下次会放宽到「带 close 的按钮全跳过」）。
4. **真站一趟 + 写交接**：自测 0 条 `ok:false` 才算验过；FMR 推送走 `upload/prepare → commit`。

## 不覆盖什么

- 只覆盖**已量到**的形状；新站的控件、时序、portal 位置都可能出新形状。
- `STABILITY_RUNS=1`：同环境复跑没量；通过一次 ≠ 每次通过。
- 工具侧自测 ≠ 生产（代理出口 / 指纹 / 时序不是一套，规格 §10）。
- 旧 py 里的骨架是**生成时冻结**的；要吃到新判据必须重新生成/重跑。
