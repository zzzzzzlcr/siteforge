### 2. 终审点名排下一刀的两条（同族：**「编一根还是能过」这条主路上的残余**）

  自造 id / `-数字` id / 跳数 > `_HOPS_LOW` 的 nth 链。**改前逐字相同**（不是回归）。
  方向：给 `_fragile` 补 `:nth-child` 一族，或把「纯位置且不脆」单列一格 —— **别顺手放宽**。
- **M3 `_norm_text` 的 `casefold()` 用在了 id / class / 属性值上**（`agent/lint.py:270` 起）：

  而 HTML 里这几个是**大小写敏感**的，这一刀要的正是「逐字」。方向偏宽松。
  修法：比 id/class/属性值时只压空白+去首尾，撇号/大小写归一只留给**文字锚**那一支。

## ② 这一刀挖出来的认识（可复用）

1. **「量不到」有两种，处置完全不同**：
   · **记录里没有**（卡是空的）—— 这是可以修的，往下看第 2 条；
   · **页面真没有**（元素身上没名字、旁边没字）—— 那三条路（删步/请人/接受）就是**唯一正解**，
     回页面现读也救不了。**别把这两种混成一句「量不到」。**
2. **★ 卡是空的，常常是「摘卡那一步丢了」，不是「页面没字」。**
   真事（`job-3e99eb67519e`，2026-10-12）：那三个 `li` 的 `target` 是 `text/role/near` 全 `null`，
   **而同一次工具调用的回执里连 `aria-label="Every now and then"` 都印出来了**。
   根因：摘卡走的 `_find_element(上一次观测的模型, 选择器)` 落空 ⇒ `_target_of(None, …)` ⇒ 全 null。
   ⇒ **「工具当场读到了、我们没带走」是这一族最划算的修法**（`a2e6967` 就是它，零风险、不动 Go）。
3. **那三个 `li` 的 CSS 面确实没有稳备选**（`alternates: []` + `stability: "low"`），
   所以判据说「只剩一根会漂的线」**不算说错**；但**语义锚是有的**（`aria-label` / `text` / `nearby_text`），
   而 `lint._has_text_anchor` 认的正是 `label`/`text`/`nearby_text`+role
   ⇒ **出口本来就留着，只是卡里没带字。**
4. **回页面现读是可行的**（spike 在真页面上走通了全程，见 `docs/probes/2026-10-15-wildnutrition-quiz-li/`）：
   那三个 `li` 今天读出来 `aria-label` 齐全，裸 DOM 里还有 `data-option-id` / `data-option-index` / 稳定的 `class`。
   **但先做 (b2) 更划算**（证据本来就在盘上）。另外它纠正了两件：
   · `-3` 组 `when` 那一屏（`CONTINUE ← BACK`）**根本没有 li** —— 那三个 li 在**点完 Continue 之后**的三屏上；
   · **那页有迟到的 cookie 横幅**（落屏后**约 10 秒**才弹，`div.pd-cookie-banner-window.cc-window`，
   点 `button.cc-allow`）+ 国际站浮层/offcanvas；不点掉，**后面每次点击都被落点守卫拒**
   （`Error: 拒绝点击 … 中心那一点上站着的是 div.Offcanvas-content wn_international_popup…`，rc=1）。
5. **探路那双手是现成的**：`agent/service.py::BitWindow`（`open()` 拿 `data.ws`、`probe()` 探活；
   `pids/alive` 的 `data` 是空 dict = 窗口不在，**别顺手 `/browser/open`**）+ `tools/cdp/cdp-mcp --ws-url <ws>`
   （stdio MCP；门上的工具见 `tools/cdp/internal/mcp/registry.go`）。
