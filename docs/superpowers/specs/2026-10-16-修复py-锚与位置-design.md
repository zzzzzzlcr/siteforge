## 1. 这件事治什么

### 1.1 一句话

**判据问的是「这根地址是不是量到的」，而它读的那份是**改稿那双手能写的那份** —— 于是「编一根」比「老实说量不到」便宜。
上一刀把判据那一头堵上了（`deps.lint(src, observed=…)`），**锚这一头还开着**。**

### 1.2 量出来的三条（本刀三件事各自的复现，2026-10-16 逐条真跑）

**① 编的锚能把判据静音，而且会被拿去页面上找元素**（终审上一刀时在容器里量的，逐字）

```
卡：{label: "Competitions", role: "a", selectors: [<脆链>]}
产物步 target {"selectors": [<脆链>]}                          → ['judge-fragile-selectors']   报
产物步 target {"label": "I made this up", selectors: [<脆链>]}  → []                              静音
```

读的是**产物自己的 `target`**：`agent/lint.py:1037` 的 `_has_text_anchor(target)`
（FILLS 那一支同形，`:1098` / `:1110`）。静音之后那根编的锚**不是躺着不动的**：
产物地址一失效就 `_relocate` 按它去页面上找元素（`agent/template.py:3290` 起）、
`_intent_score`（`:2360`）按它给候选打分。**判据被静音 + 重放被带偏，是同一根编的锚干的两件事。**

**② 空卡上，纯位置地址判「量到过」**（`li:nth-child(2n+1)` 一族）

```
空卡 + li:nth-child(2n+1)                      → 不报       ← 洞
空卡 + div:nth-child(1) > a:nth-child(1)       → 不报       ← 洞
空卡 + body:nth-of-type(1) > a:nth-of-type(1)  → 不报       ← 洞
空卡 + div > a:nth-of-type(1)                  → 报 judge-fragile-no-basis
```

⚠️ **最后那条报，与 `_fragile` 无关**（它 `_fragile` 也是 `False`）—— 它报是因为裸标签 `div`
算断言、空卡里没有 ⇒ `address_basis` 判 `unsupported`。
真正静音的那一族是**零断言**：`address_basis`（`agent/lint.py:495`）对零断言返回
`OBSERVED`，人话写着「这条地址**只说了位置、没主张任何身份**」——
**判据自己的人话在说「它什么都没主张」，判据的账却把它记成「有据」。**
于是它成了「一根不脆的采信候选」⇒「有答案」⇒ 放行。

**③ 判据说「逐字对上了」，真站上找不到**

```
#Postcode  vs  #postcode                → 断言完全相同 [('id', 'postcode')]
[name=Postcode] vs [name=postcode]      → 断言完全相同 [('attr', 'name=postcode')]
产物写 #postcode、观测原文 #Postcode     → address_basis 判 observed：「每一条都回原始观察里对上了」
```

而重放那边是 `Element.matches("#postcode")` —— id / class / 属性值在 HTML 里**大小写敏感**。
根因：`_norm_text`（`agent/lint.py:270`）里那个 `casefold()` 本来是给**文字锚**写的尺子
（「同一个字的两种排版写法算同一个字」），却也被用在了 id（`:364` `:371`）、class（`:373`）、
属性值（`:366`）上。

### 1.3 三条的共同形状

**判据的最后一寸在给一根它自己都不信的东西背书。**
①是「读错了那一份」（读了可改的，不是冻结的）；②是「把位置当成了主张」；③是「把代码里的名字当成了印出来的字」。
三条都不改判据的**口径**，只改它**据以判的那件事**。

## 2. 目标与非目标

**目标**

1. 产物的锚**只能来自冻结那份** —— 编的锚进不了产物（I1）；
2. 零断言的地址**不再给空卡背书**（M2）；
3. id / class / 属性值**逐字比**，与重放那边 `matches()` 同一条尺子（M3）；
4. 三处都是**往紧里收**，因此**先量再改**（§5）。

**非目标**

- 不改 `_fragile` 那两族的定义（§3.3 末尾说清了为什么）；
- 不改判定「无据可依」的口径本身（那是上一刀定的，本刀一个字不动）；
- 不改 `selectors` 的归属（那是改稿那双手要换的东西，§3.1 规则第 3 条）；
- 不动 `FILLS[*].label`（§7 第三件，先量）。

## 3. 设计

### 3.1 I1 —— 渲染取数点：锚只认观测

**一句话**：产物里那几步的锚，从冻住的 `state["observed"]` 来，不从可改的 `states` / `fills` 来 ——
与判据那一处取同一份。

**规则**（对每一组、每一步）：

1. `card = fix.find_observed(observed, 组名, 步序, fix.card_of(target))`；
2. **卡 falsy ⇒ 这一步一个字不动**（新加的步 / 步序越界 / 没这一组）——
   判据那边 `_card_has_nothing` 已经 fail-closed（`agent/lint.py`），
   而「声明里不给选择器、全靠运行期 `observe` 认池子」那一族纯意图步不会被误杀；
3. 卡有 ⇒ `target` 里那 **7 个锚键**（`label` `aria_label` `hint` `placeholder` `nearby_text`
   `text` `role`）**整份照卡覆写** —— 卡上有就写卡上的值，**卡上没有就把键删掉**；
4. `selectors` 一个字不动。

**`role` 为什么在合并键里、却不在 `lint._CARD_ANCHOR_KEYS` 里**：那不是笔误 ——
那边问的是「这张卡说得出这一格是什么吗」（`_card_has_nothing` / `_card_has_semantics` 用），
这边问的是「这一步的 target 该写哪几样」。两个问题两把尺子，**别为了「看着一致」把它们并成一把**。

**落点**

| 改哪 | 怎么改 |
|---|---|
| `agent/fix.py` | 新增纯函数 `anchors_from_observed(states, fills, observed) -> (states, fills, changes)` —— 卡的手艺（`card_of` / `find_observed`）已经全在这个文件里，合并是它的第四个消费者 |
| `agent/template.py` `render()` | 加**关键字形参** `observed=None`（老调用点一个字不用改）；排在 `_steps_must_be_findable` **之前**（见 §3.2） |
| `agent/graph.py` `_draft` 出稿那一处 | 传 `observed=state.get("observed")` |
| `agent/graph.py` `_deliver` 交付前重渲那一处 | 同上 —— **两处必须同一把尺子**，否则交付出去的那串字节与 lint 过的那版不是一份 |

⚠️ 行号别照抄（工作区里常年压着别人的改动）：按**符号**找 —— `template.render`、
`_draft` 里那处 `template.render(...)`、`_deliver` 里那处。

**`FILLS[*].target` 一起合**：同一条规则、同一个函数（fill 那一支按**键**找卡，
`lint._rule_g` 已经是这么取的）。不一起改的话，`:1098` 那一支读的正是 fill 的 `target`，
等于留半扇门。

**不传 `observed` ⇒ 与从前逐字节相同**（老 job 没有那一格，回落旧行为 —— 与判据那一处的口径一致）。

**这份合并只做「覆写」，不做「钉回去」**：与上一刀 §3.7 同一条立场 ——
冻的是**探路那一刻**的事实，不是「上一版」。

### 3.2 I1 的连带：合并排在 `_steps_must_be_findable` 之前

`template._steps_must_be_findable` 判的是「既没有选择器、也没有意图」的步 ——
它的立意（2026-09-24 solarincentives）是「这种步骤不该到得了产物，而且要说第几步」。

合并要排在它**前面**（合完再判），因为**产物里那一步就是探路量到的那一步**，
判就该判要写出去的那一份。

**唯一的连带**：一条「没有选择器、只靠 `text` 认」的步，如果**它的卡也是空的**，
合完就变成「既没地址也没锚」⇒ **当场拒稿、点名第几步**。

这是**新的硬失败**，所以按仓里的规矩**先量**（§5 第一组数）。

**边界（写清楚，别外推）**：卡**上有锚**、而地址是纯位置的，**仍然不报**（§3.3）——
那一格有锚可依，重放能按锚找回（I1 之后锚一定在产物里）。本刀收的只是**空卡**那一格。

### 3.3 M2 —— 零断言地址不给空卡背书

**改法（一处，窄）**：`_card_has_nothing`（`agent/lint.py:1144`）——
「采信的候选」得**说了点什么**才算数：

```python
return not [s for s in (kept or []) if not _fragile(s) and assertions_of(s)]
```

理由一句话：**位置不是断言**（§3.2 自己的口径），所以一条零断言的地址证明不了任何事 ——
把它算成「有答案」，就是让判据自己的人话去给一根漂的地址背书。

**为什么不动 `_fragile`**：给 `_fragile` 补 `:nth-child` 一族，会连带把
`ul li:nth-child(2) a[href="/x"]` 这种**带真锚**的地址也判脆 —— 那是扩大打击面，不是修这个洞。
洞在「零断言被当成有据」，不在「nth 不够脆」。

**连带**：`_no_basis_sel` 是**一处定义、两个消费者**（`_rule_i` 与 `no_basis_slots`）——
这一改会同时把这类步加进「请人接受」那份待接受清单。那是**对的**（§3.5 的三条正路本来就含「接受」），
但要在 §5 里量出来。

### 3.4 M3 —— 标识不 casefold

**一把尺子劈成两把**：

| 尺子 | 用在哪 | 怎么算 |
|---|---|---|
| **文字**（`_norm_text`，不动） | `("text", …)` 那一支（`:359`）；卡上的 `label` / `hint` / `placeholder` / `nearby_text` / `text`（`_observed_facts_and_hint`） | 去首尾 + 压空白 + 撇号归一 + `casefold()` |
| **标识**（新增 `_norm_ident`） | `id`（`:364` `:371`）、`class`（`:373`）、属性值（`:366`） | 去首尾 + 压空白。**不 casefold、不撇号归一** |
| **标签名** | `:376` `:400` | 照旧 `casefold()` —— HTML 的标签名本来就不分大小写，这里是对的 |

**连带**：这是**往紧里收**。产物把观测到的 `#Postcode` 写成 `#postcode` 从此判「对不上」⇒
走「换一根沾着卡的地址」那条正路。先量（§5 第三组数）。

**边界**：`_verbatim`（与观测原文逐字相同 ⇒ `OBSERVED`）**排在前面**，所以
「把卡上那根原样抄回来」照旧放行 —— 本刀收的是**改写**，不是**照抄**。

### 3.5 可见性：闸上摆出「哪几步的锚被观测改写」

锚被覆写是**静默**的，而「改稿那双手在编锚」这件事唯一的可见面就是它。

**做法**：`anchors_from_observed` 的第三个返回值 `changes` =
被改写的那些位置的清单（`"组名#步序"` 与 `"FILLS[键]"` 两种形状）。
`graph._draft` 拿它在 facts 里摆一格 `"锚被观测改写的步"`；**空就不摆**（与邻居那几格同一个习惯）。

`_draft` 为此把那把**纯函数调两次**（一次取清单、`render` 内部再调一次）——
**同一个函数调两次，不是两份实现**。这是刻意的：宁可多算一遍，也不给「清单与产物不一致」留缝。

⚠️ 报数要连口径一起报（上一刀交接单 ③.1 的教训）：这一格摆的是**位置清单**，不是一个计数。

## 4. 数据形状与兼容

| 改什么 | 形状 | 兼容性 |
|---|---|---|
| `template.render(...)` | 多一个**关键字形参** `observed=None` | 老调用点一个字不用改；**不传即旧行为（逐字节相同）** |
| `fix.anchors_from_observed(states, fills, observed)` | 新纯函数 → `(states, fills, changes)` | 新函数；`observed` falsy ⇒ 原样返回、`changes` 空 |
| `_card_has_nothing(card, kept)` | 末句加 `and assertions_of(s)` | **只影响「有没有答案」那一格**；卡上有锚 / 卡上有不脆候选那两条前置分支一个字不动 |
| `lint._norm_ident` | 新函数 | 只换 id / class / 属性值那几处的尺子；文字那一支一个字不动 |
| 产物本身 | **形状不变** | 锚的**值**可能变（变成观测值）、可能的键变少（卡上没有的）—— 读产物的人不受影响 |

**老 job**（没有 `observed` 那一格）：两处渲染点取到的都是 `None` ⇒ 整条路回落旧行为。
与判据那一处（`deps.lint(src)` → `deps.lint(src, observed=…)`）同一条兼容口径。

## 5. 验收条件 + 量证

### 5.1 三组量证（三处都是往紧里收 ⇒ 先量再改）

## 6. 裁定（2026-10-16，用户）

三条都是**用户当场拍的**，不是控制方推的：

1. **锚的归属** —— **卡找到 ⇒ 锚只认卡（多出来的删掉）；卡找不到 ⇒ 原样不动**。
   选它而不选「锚一律只认观测」的理由：后者会撞 `_steps_must_be_findable`，
   把「没有选择器、靠 `text` 认」那一族（仓里明确有）当场拒掉，或者为了不拒就得把判据挪到合并之前
   —— 而那样产物里仍留着一条空步，**等于把问题从闸上挪到真站上**。
2. **合完再判**（§3.2 那条连带）**认**，但**先量**：0 条直接上；不是 0 把单子拿回来裁。
3. **可见性那一格**（§3.5）**加**。

## 7. 明确不做（再写一遍，防跑偏）

1. **第 2 处取数点（提示词）不做** —— `fix.states_user(spec, *, …)`（`agent/fix.py:824`；
