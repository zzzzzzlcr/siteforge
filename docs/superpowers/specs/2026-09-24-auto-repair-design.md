# 自修复（检测到就开修）—— 设计

日期：2026-09-24 · 状态：**待你审**（审过才写实施计划）

## 1. 目的与成功判据

**领导的原话（用户转述）**：用**给的日志和截图**让 AI **自修复**；**修两遍不通才抛给人**。
**用户补充**：**人连「开修」都不用喊** —— 后端会给一个「**同一个站连续失败 5 次**」的榜单，
我们**检测到就自己开修**；两遍不成才落到**人现在用的那个失败榜**（＝「确认 AI 自己搞不定，
需要人协助」）；修的时候**要切到那一单对应的国家代理**。

**成功判据（可核的四条）**

1. 榜上冒出新的一串失败 ⇒ **没人按**，自己开修（时间线与账本里都留痕迹）；
2. **两遍之内通了** ⇒ 自动上传到后端，且**回读一致**（不一致 ⇒ 自动回滚 + 报人）；
3. **两遍不通 / 做不成** ⇒ 停下，并在面板上**那一单**打标 + 「自动修的活」那一栏写明**为什么需要人**；
4. 人看的失败榜上，**不会有**「AI 正在修」的单被读成「没人管」那种含糊状态。

## 2. 现状（事实，都是本仓今天的代码/实测）

| 这件事 | 今天在哪一步 |
|---|---|
| 修复那条路 | **有**：底稿从后端读（`formScript`）→ 出稿（模型改源码 / 模板重渲染）→ 过闸 → 自测 → 落盘 → 上传（`service` 的 `mode=fix`） |
| 用**日志** | **已经在喂**：「给模型的证据（旧脚本停在哪儿）」= 那一趟的逐步记录 + 旧脚本自己打的错 |
| 用**截图** | ⚠️ **链是断的**：图会拍会存，但要 AI **看**图需**视觉模型**，本机没配（`inspect_image` 报 model does not support image input） |
| 「两遍不通就停」 | **判据已有**：`Caps` 里 lint 打回 2 次 / 自测挂 2 轮 ⇒ 停（`graph.py`） |
| 补丁没过闸再补 | **已有**（`fix.PATCH_ATTEMPTS=3`，**人不在环**） |
| 换代理国家 | **已有**：面板那一格走 `/country`，判据是「**核到了**」 |
| 上传那三下 | **已有**：预检 → 确认 → **回读一致**；不一致自动回滚 |
| **不用人按** | ✗ **缺的就是这一块**：每一道闸都 `interrupt()` 等人（`graph._enter`） |
| 自动触发 | ✗ 没有：今天一律「人点一下才开一趟」 |

## 3. 骨架与职责（已定：②值班脚本）

| 谁 | 只做这些 |
|---|---|
| **值班脚本**（宿主上，与 `tools/relaunch-svc.py` 一族放一起；不进容器） | 看榜 → 对账 → 开修（`POST /run` + `auto: true`）→ 记账 → 看它到头 → 报人 |
| **服务** | 自动应答闸、**先切国家**（核到了才开）、两遍的判定与停、自动上传三下 + 回读、面板上那两处 |
| **页面** | 只搬字（既有纪律：页面一个判断都不许有） |

**为什么拆成这样**：脚本挂了也**写不坏生产**（它不碰 gost、不碰产物、不写后端）；而「修/判/传」
那条链今天就在服务里，一个字都不用搬。

## 4. 触发与对账

- **每 5 分钟**拉一次后端那个连续失败榜（形状待量，见 §10）。
- **同一站、同一串连续失败，只开修一次**：账本里记「这个站键 + 这一串的起点/次数」；
  已有未结案的活、或上一趟就是为**这同一条串**开的 ⇒ 不开第二趟。
- **一次只修一个**（今天一次只有一个真窗口）⇒ 榜上同时冒 3 个新的就**排队**一个一个来。
- **心跳**：每轮往 `runtime/auto/heartbeat` 写一行；**超过 15 分钟**（= 连着 3 轮没写）没有 ⇒
  **面板上报警**（无人值守最坏的形状是「没人看的时候它死了而没人知道」）。

## 5. 服务里的自动模式（`auto: true`）

**机制（关键取舍）**：**不改图的那道闸**。图的契约（每个花钱/动真页面的节点之前 `interrupt()`）
**一个字不改**；自动那半是**服务侧的一个自动应答回路** —— 看到闸口就**替人按「继续」**，
并在时间线上记一条「**自动模式：这一步自己走了**」（有痕迹，不许静默）。好处：图不用动 ✓
人**随时能接手**（他按就是他按 ✓ 两边不会打架：应答只开在带 `auto` 的那一趟上）。

1. **开修之前先切国家**：读那一单失败记录里的国家 ⇒ 有映射就调既有的换链路 ⇒ **核到了才开修**。
   **三种一律不猜、直接报人（不开修）**：国家**代号不认识**（如今天那条 `AU`）、那一单**没记国家**、
   **核不到**。
2. **判据那两格**：自动模式**沿用**既有那条「从底稿搬」（`SUCCESS_TEXTS` / `SUCCESS_URL_MARKERS`）——
   **不新开口径**；搬不出来 ⇒ 报人（同今天）。
3. **「一遍」的定义**：**出一版稿 + 自测跑一次**（按 2026-09-24 的裁定：自测只跑基线 ⇒ **1 次真提交**）。
   **稿没出成 / 过不了闸也算一遍**（不然它会无限重出）。自测没过 ⇒ 把**诊断**回灌、再出一版 ⇒
   第二遍仍不过 ⇒ **停、报人**。⇔ 这与 `Caps` 今天那条「自测挂 2 轮就停」**本来就是同一条线**，
   不新造判据。**计数在服务这一侧**（只有它看得见这一趟的诊断与过闸记录；
   账本里那几格是**结果**，不是计数的地方）。
4. **「做不成」与「没人按」分开**：窗口没了 / 缺旋钮 / 底稿读不到 / 国家那三种 ⇒
   **立刻报人**（**不等两遍** —— 再试也不会变）。
5. **两遍之内过了** ⇒ 自动跑上传那三下（预检 → 确认 → **回读**）：回读一致 = 成了；
   不一致 ⇒ **自动回滚 + 报人**。一趟的**真流量上限 = 2 次**（两遍 × 基线 1 次）。

## 6. 护栏（数已拍：2026-09-24）

| 闸 | 值 |
|---|---|
| 一次修几个 | **1**（串行） |
| 每站每天 | 最多 **1 趟**自动修（同一串只开一次；第二天又连挂 5 次 = 新的一串 ⇒ 可以再修） |
| 每天总共 | 最多自动开修 **10 个站**；到顶 ⇒ **停下并报人**（「今天到顶了，还剩 X 个没修」+ 清单，**不静默少修**） |
| 一趟真提交 | 最多 **2 次** |
| **总开关** | **默认关**（你打开才跑；先手动跑一两天看结果再常开） |
| 一键停 | 面板上一个按钮：停循环 + 不新开活（正在跑那一趟走既有的「停」） |
| 别碰名单 | 一个显式名单（站键），命中就不开修、报人；**不另设**「赚钱站」那一档（多一层规则多一处维护） |
| **停用站** | **默认不自动动**；**自动模式下不许上传到「停用」的行**（上传会**重新启用**它 ⇒ 遇到就报人） |
| 账 | `runtime/auto/…` 一本账：谁、何时、哪串、切了哪国、两遍结果、传没传、哈希 |

## 7. 通报（只落面板，第一版不加外部通知）

1. **失败榜那一行打标**：「**AI 自己修过两遍没成，需要人**」——标是**服务算的**（拿自动账本对账），
   页面只搬字。**不藏那一单**（它本来就失败了），只是让人知道「自动那条路已经试过了」。
2. **新一栏「自动修的活」**：一站一行 —— 站键 / 第几串失败 / **切了哪国** / 两遍各什么结果 /
   停在哪一步 / 产物落在哪 / 传没传 / **为什么需要人**。
3. **「为什么需要人」两类分得开**：① **做不成**（国家那三种、底稿读不到、缺旋钮、窗口没了）
   ② **两遍没过**（附两遍各自的诊断 + 卡在第几步）。

## 8. 前置与验收

**前置**
- **视觉模型**（要「AI 看截图修」就必须有）：本机没配 ⇒ 第一版**只用日志/证据修**，
  截图照拍照存（留证据）但 AI 不看；你给模型名后再接。
- **后端那个连续失败榜的口**：第一步就是**量它的形状**（字段、上限、要不要 token）。

**怎么验（先不碰真站）**
1. **假后端**（录一份榜 + 一份失败记录）⇒ 验「检测到 → 开修 → 记账 → 打标 → 报人」整条；
2. **自动走闸那一半**：用现有的无窗口桩 ⇒ 验「**不等人**、两遍后停、说清为什么」；
3. **切国家那一半**：拿今天那条真数据（`AU` 这类不认识的代号）当靶子 ⇒ 验「不猜、不开修、报人」；
4. **真站那趟**（含自动上传 + 回读）**必须你点头**才跑 —— 挑一个你能接受被自动动的站。

## 9. 第一版明确不做

邮件/群等外部通知 ✗ · 并行修多个站 ✗ · AI 看截图修（等视觉模型）✗ · 写回后端失败榜 ✗ ·
「连续 5 次」这个判据自己实现一遍（**后端定义，我们只消费**）✗

## 11. 风险（说清）

- **无人值守会换生产那份**：我们给的护栏 = 每天 10 个站 + 一趟 2 次真提交 + 回读一致 + 回滚 +
  **总开关默认关**；剩下的靠「别碰名单」；
- **国家映射不全**：不认识的代号**绝不猜**（宁可报人 —— 猜一个国家 = 用错地区跑真流量）；
- **榜单口径在别人手上**：「连续」怎么算由后端定 ⇒ 它改了我们要跟着改（设计里不重复实现）。
