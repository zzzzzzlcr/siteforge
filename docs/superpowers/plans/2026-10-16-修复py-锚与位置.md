# 修站第二刀：锚与位置 —— 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让产物里那几步的**锚**只能来自探路那一刻量到的那一份（编的锚进不了产物），
顺手把判据最后两处「给它自己都不信的东西背书」堵掉：零断言的地址不再算「有答案」、
id / class / 属性值不再拿大小写归一。

**Architecture:** 探路收尾冻的那份（`state["observed"]`，上一刀 Task 1 已有）**多一个消费者**：
`fix.anchors_from_observed` 把卡上的锚合进产物的两张表，`template.render` 在
`_steps_must_be_findable` **之前**调它、两处渲染点（出稿 / 交付前重渲）都传同一份 `observed`。
判据那侧两处各改一句尺子（`_card_has_nothing` 末句、`_norm_text` 劈成两把）。

**Tech Stack:** Python 3 · LangGraph（图 + checkpoint）· pytest · `tools/cdp`（Go 二进制，**本计划不改**）

**Spec:** `docs/superpowers/specs/2026-10-16-修复py-锚与位置-design.md`

## Review Focus

（spec 是愿景文档；它没写到的输入不等于可以崩。这几类是**最可能咬到人**的，每一条都在某个 Task 里有测试钉住。）

1. **老 job / 老调用点（没有 `observed`）**：`render` 与判据都必须**退回今天的行为**，不许因为
   「没有冻结那份」就一片红 —— 尤其 `tools/rerender_site.py` 那条**重渲已交付产物**的路。
2. **卡是空的那一种**（观测那一步存在、但身上什么都没有）：**「量过、什么都没有」与
   「没量过这一步」不是一件事** —— 前者要**删掉**模型编的锚，后者一个字不动。
   判据那边两者同义（Ruling 8），这一边**不同义**。
3. **合并把一步掏空**：一条「没有选择器、只靠 `text` 认」的步，卡也是空的 ⇒ 合完就认不出来了。
   这时必须**当场拒稿并点名第几步**（不是静默放行，也不是挂在那儿）。
4. **表被重排 / 地址被改写**：卡按指纹认（`find_observed` ①），认不出才落 (组名, 步序)。
   合并**不许**因为「地址被改写了」就把那一步当成「没量过」跳过。
5. **同一根地址同时出现在两处**（两组的第 3 步同一根脆链）：合并与判据都要**指着这一步**说，
   一处改了不许顺带把另一处也改掉。

```python
#: 产物里**从观测来的那几样**（锚）= `CARD_KEYS` 去掉 `selectors`。
#: `selectors` 不在里头是**故意的**：它是**候选**，是改稿那双手要换的东西（spec §3.7）。
#: ⚠️ 与 `lint._CARD_ANCHOR_KEYS`（6 个，没有 `role`）**不是同一把尺子**，别并：
#: 那边问「这张卡说得出这一格是什么吗」，这边问「这一步的 target 该写哪几样」。
CARD_ANCHOR_KEYS = ("label", "aria_label", "hint", "placeholder", "nearby_text", "text", "role")


def _merge_anchors(target, card):
    """一个 target → `(照卡覆写锚的那一份, 有没有**改写**过)`。**新 dict**，入参不动。

    ⚠️ **「改写」的定义是窄的**（spec §3.5 那一格的全部信噪比都在这两句上）：
      · **模型写过一根非空的锚，而卡上不是那一根**（含「卡上压根没有 ⇒ 删掉」）⇒ **算**；
      · 模型没写、卡上补上 ⇒ **不算**（那是**补**，不是编）；
      · 模型写的是 `None` / 空串 / 空表 ⇒ **不算**（那是空值，不是主张）。
    不收窄的话，账本里那几样锚键大量是 `None` 占位（`{"text": None, "label": None, …}`），
    照卡一覆写就「有差异」⇒ **每一版都记成「改写过」**⇒ 那一格成了常亮的灯，人就不看了。
    """
    src = target if isinstance(target, dict) else {}
    out = dict(src)
    overwrote = False
    for key in CARD_ANCHOR_KEYS:
        before = src.get(key)
        after = copy.deepcopy(card[key]) if key in (card or {}) else None
        if after is None:
            out.pop(key, None)          # 卡上没有 ⇒ 产物里也不许有
        else:
            out[key] = after
        if before not in (None, "", [], {}) and before != after:
            overwrote = True
    return out, overwrote


def anchors_from_observed(states, fills, observed):
    """把**冻结那份**的锚合进产物那两张表（spec §3.1，本刀 I1）。→ `(states, fills, changes)`

    三条规则（别外推）：
      ① **卡找得到** ⇒ `target` 里那 7 个锚键（`CARD_ANCHOR_KEYS`）**整份照卡覆写** ——
         卡上有就写卡上的值，**卡上没有就把键删掉**；
      ② **卡找不到**（新加的步 / 步序越界 / 没这一组）⇒ **那一步一个字不动**；
      ③ `selectors` 一个字不动（§3.7：候选归改稿那双手）。

    ⚠️ **`{}` 与 `None` 在这里不是一件事**（判据那边同义，见 `lint._observed_card` 的 Ruling 8）：
      · `None` = **没量过这一步**（原件里找不到对应的一步）⇒ 一个字不动；
      · `{}`  = **量过、什么都没有**（原件那一步存在、`target` 是空的）⇒ 模型的锚**全删**。
    写成 `if not card` 会把后者当成前者 ⇒ 「空卡上编一根」那条路又开了（spec §1.2 ② 正是它）。

    ⚠️ **`fills` 只认 dict**：`observed_of` 那边就是 `dict(fills or {})`（list 形状在那里就炸了），
    所以能走到这一行的 `fills` 一定是 dict；不是就原样返回（**不猜、不静默改形状**）。

    ⚠️ **纯函数**：入参两张表一个字节不动（`anchors_from_observed` 的调用方是 `render`，
    而 `render` 上游还拿着那张可改的表）。
    """
    if not isinstance(observed, dict) or not observed:
        return states, fills, []
    changes: list = []
    frozen_states = observed.get("states")
    if not isinstance(frozen_states, list):
        frozen_states = []
    out_states: list = []
    for group in (states or []):
        if not isinstance(group, dict):
            out_states.append(group)
            continue
        name = str(group.get("name") or "?")
        steps: list = []
        for index, step in enumerate(group.get("steps") or []):
            if not isinstance(step, dict):
                steps.append(step)
                continue
            target = step.get("target")
            card = find_observed({"states": frozen_states}, name, index, card_of(target))
            if card is None:                       # 没量过这一步 ⇒ 一个字不动（规则 ②）
                steps.append(step)
                continue
            merged, overwrote = _merge_anchors(target, card)
            if overwrote:
                changes.append("%s#%d" % (name, index))
            steps.append(dict(step, target=merged))
        out_states.append(dict(group, steps=steps))
    if not isinstance(fills, dict):
        return out_states, fills, changes
    frozen_fills = observed.get("fills")
    if not isinstance(frozen_fills, dict):
        return out_states, fills, changes
    out_fills: dict = {}
    for key, fill in fills.items():
        frozen = frozen_fills.get(key)
        if not isinstance(fill, dict) or not isinstance(frozen, dict):
            out_fills[key] = fill               # 冻结那份里没这一格 ⇒ 原样（规则 ②）
            continue
        merged_target, overwrote = _merge_anchors(fill.get("target"),
                                                  card_of(frozen.get("target")))
        if overwrote:
            changes.append("FILLS[%s]" % key)
        out_fills[key] = dict(fill, target=merged_target)
    return out_states, out_fills, changes

"""修站第二刀的量证：三处「往紧里收」各会新咬到几条。**只读**打开账本。

## 为什么要先量（spec §5.1）

本刀三处改动**都是往紧里收**，按仓里的规矩先量再改 —— 不然就是拿真语料赌。

| 桶 | 数什么 | 硬线 |
|---|---|---|
| **① 合并后新拒的步** | 用冻结那份合并之后，那条步「既没选择器也没锚」⇒ `_steps_must_be_findable` 会当场拒稿 | **0** |
| **② 空卡上的纯位置地址** | 今天放行、新规会报 `judge-fragile-no-basis` 的 | 单列交人裁 |
| **③ 只差大小写的标识** | 今天判 `observed`、新规判 `unsupported` 的 | 单列交人裁 |

**冻结那份怎么来**：账本里**没有** `observed` 那一格也能量 —— `_freeze_observed` 冻的就是
**第一次出稿时那张表**，而**第一版 `states`/`fills` 就是它**（build 路是 `journey.states()`、
fix 路是 `fix_states`，两条路的第一版都逐字等于冻的那份）。所以直接用**最早那一条**
（`addr_basis_report._rows` 已经按这个口径给）。真冻过的那份在就优先用它（同 `addr_basis_report`）。

⚠️ **不许为了让 ① 变绿而放宽规则** —— 那是这条硬线的全部意义（与上一刀 §5 同一条）。

## 用法（**在宿主上跑**，账本在宿主）

    python3 tools/anchor_report.py --ledger runtime/checkpoints.sqlite     # 8099 生产
    python3 tools/anchor_report.py --ledger runtime-222/checkpoints.sqlite # 8100 测试
"""
from __future__ import annotations

import argparse
import pathlib
import sys

ROOT = pathlib.Path(__file__).resolve().parents[1]
sys.path.insert(0, str(ROOT))
sys.path.insert(0, str(ROOT / "tools"))     #: `_rows` / `_site_of` 住在隔壁那个工具里

from agent import fix, lint, template  # noqa: E402
import addr_basis_report as basis      # noqa: E402  （同一份「账本怎么读」的定义）


def _frozen_of(ch):
    """这一趟冻结的那一份 —— 有就优先用（与 `addr_basis_report` 同一条口径）。"""
    got = next((x for x in reversed(ch.get("observed") or []) if x is not None), None)
    if got is not None:
        return got
    states = (ch.get("states") or [None])[0]
    fills = (ch.get("fills") or [None])[0]
    if states is None and fills is None:
        return None
    return fix.observed_of(states, fills)


def _findable(states) -> bool:
    try:
        template._steps_must_be_findable(states)
        return True
    except ValueError:
        return False


def measure(ledger: str) -> dict:
    """三个口径的分账 → `{桶名: [(thread_id, 站名, 位置), …]}`。"""
    out = {"①合并后新拒的步": [], "②空卡上的纯位置地址": [], "③只差大小写的标识": []}
    for tid, ch in sorted(basis._rows(ledger).items()):
        frozen = _frozen_of(ch)
        if not frozen:
            continue
        site = basis._site_of(ch)
        versions = [v for v in (ch.get("states") or []) if isinstance(v, list)]
        if not versions:
            continue
        # ① 只看**最后一版**（要交出去的那一版）：合并后认不认得出来
        merged, _, _ = fix.anchors_from_observed(versions[-1], ch.get("fills", [{}])[0] or {},
                                                 frozen)
        if not _findable(merged):
            for group in merged:
                for index, step in enumerate((group or {}).get("steps") or []):
                    one = [dict(group, steps=[step])]
                    if not _findable(one):
                        out["①合并后新拒的步"].append(
                            (tid, site, "%s#%d" % (group.get("name"), index)))
        # ② / ③ 逐版看（判据是纯函数，逐版才是它在生产的每一次判决）
        for version in versions:
            for group in version:
                for index, step in enumerate((group or {}).get("steps") or []):
                    target = (step or {}).get("target") or {}
                    sels = [str(s) for s in (target.get("selectors") or []) if str(s or "").strip()]
                    if not sels:
                        continue
                    card = fix.find_observed(frozen, str((group or {}).get("name") or "?"),
                                             index, fix.card_of(target)) or {}
                    if lint._card_has_nothing(card, sels) and any(
                            not lint.assertions_of(s) for s in sels):
                        out["②空卡上的纯位置地址"].append((tid, site, sels[0]))
                    for one in sels:
                        for other in (card.get("selectors") or []):
                            level, _ = lint.address_basis(one, card, card.get("selectors") or [])
                            if level == lint.UNSUPPORTED and \
                                    str(one).strip().casefold() == str(other).strip().casefold():
                                out["③只差大小写的标识"].append((tid, site, one))
    return out


def main(argv=None) -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--ledger", required=True)
    ap.add_argument("--limit", type=int, default=30)
    args = ap.parse_args(argv)
    got = measure(args.ledger)
    for name, rows in got.items():
        print("%s：%d" % (name, len(rows)))
    print("①必须是 0；②③逐条列出来交人裁（不许为了让它们变绿而放宽规则）")
    for name, rows in got.items():
        for one in rows[:args.limit]:
            print("  %-22s %-24s %s  %s" % (one[0], one[1], name, one[2]))
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```
