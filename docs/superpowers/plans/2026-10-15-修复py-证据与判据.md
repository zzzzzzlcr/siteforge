# 修站那一刀：证据与判据 —— 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 lint 判「地址够不够稳」之前先验**出处**——判据要的答案是**探路那一刻量到的**，
不是模型编的；量不到时就如实说量不到，不再逼模型编一根。

**Architecture:** 探路收尾时把 `states`/`fills` **整份冻一份**（`state["observed"]`，模型没有写它的通道）。
`lint` 多接一个只读参数 `observed`：把待检查的地址拆成「断言」，逐条回冻结那份里找同一个属性名+值，
分成 Observed / Derived / Unsupported 三级，再按四级格子分派（过 / 有据没用上 / 未证实 / 无据可依）。
「接受」只能由人在闸上给，且绑死四元组、任一变化即失效。

**Tech Stack:** Python 3 · LangGraph（图 + checkpoint）· pytest · `tools/cdp`（Go 二进制，**本计划不改**）

**Spec:** `docs/superpowers/specs/2026-10-15-修复py-证据与判据-design.md`

## Global Constraints

- **只吃存量**：不回页面现读、**不改 Go**、不动 `Caps`（`max_lint_bounces=2` / `max_diagnoses=2`）、
  不动 `repair_stuck`、不动 `fix.check_patch` 那五条闸、不动面板（`agent/console.html`）。
- **判据只判结构**：出处判据**不判对错**（对不对由自测和人说了算）——与 `fix.check_patch` 同一条立场。
- **fail-closed 的方向不许反**：认不出出处 ⇒ 当「没量到」，**不许**当「量到了」；
  人说的话解析不出「接受」⇒ **不认**，不许猜。
- **新旧行为必须可退回**：`observed` 不传（`None`）时，判据行为与今天**逐字节一致**——
  老 job、老测试、别的调用点不受影响。
- **人话不许编**：每条 message 都要说清「哪一步、凭什么、下一步能做什么」。

## Review Focus

（spec 是愿景文档；它没写到的输入不等于可以崩。这五类是**最可能咬到人**的，每一条都在某个 Task 里有测试钉住。）

1. **旧产物 / 老 job（没有 `observed`）**：判据必须**退回今天的行为**，不许因为「没有冻结那份」就一片红。
2. **模型的表被重排 / 加了几步**：按 (状态名, 步序) 对不上原件时，要能救回来（卡指纹），
   救不回来才说「找不到对应的一步」——**不许**把重排判成「编造」。
3. **同一根地址同时出现在两处**（两组的第 3 步用了同一根脆链）：报告要指着**这一步**说，
   一处被接受不能顺带把另一处也放行。
4. **`observed` 里那一步本来就没有 `target`**（`goto` 步、`observe` 步）：判据不许在这些步上报出处问题。
5. **人写的那句「接受」写错一个字符**：**不认**（不静默当成接受），并把「没认出来」说出来。

```python
# ── 原始观察：探路那一刻量到的那几样（★ 2026-10-15 修站那一刀）──────────────
#
# 为什么要有这一节（spec `docs/superpowers/specs/2026-10-15-修复py-证据与判据-design.md` §3.6b/§3.7）：
# `lint` 要判「这根地址是不是量到的」，而**判据跑在待检查的那份 src 上**。
# 待检查的那份是**改稿那双手写的** ⇒ 拿它当证据就是**循环证明**：
#   模型编一根 `header a` → 写进 states → 判据从 states 读证据 → 认为有出处 → 放行。
# 所以证据必须是**另一份**、而且是模型**写不到**的一份：探路收尾时冻的 `observed`。
#
# ⚠️ 冻的是 `states` + `fills` 两张表的**整份拷贝**（不是只抽卡）：
#   · 卡从它里面读（判据只读卡字段与 `selectors`，见 `card_of`）；
#   · 整份拷的代价是多几百 KB 的 checkpoint —— 换来的是「以后要读别的格」不用再改冻结协议。

#: 一张「卡」里放哪几样 —— **探路那一刻量到的身份证据**。
#: ⚠️ `selectors` 在里头：它装的就是工具当时给的 `selector` + `alternates`
#: （`_selectors_of` 搬进来的），而 `tools/cdp` 那边的 `address()` 已经把
#: **每一条都验过唯一**（唯一不了就如实降 `stability: low`）。
CARD_KEYS = ("label", "aria_label", "hint", "placeholder", "nearby_text",
             "text", "role", "selectors")


def card_of(target) -> dict:
    """一个 target → 那张卡（**只有卡字段**；值为空的不进来）。

    空 / 不是 dict ⇒ 空 dict（那张卡就是「什么都没有」—— 与「读不出来」在这一层同义，
    判据那边按「没量到」处理）。
    """
    if not isinstance(target, dict):
        return {}
    out: dict = {}
    for key in CARD_KEYS:
        value = target.get(key)
        if value in (None, "", [], {}):
            continue
        out[key] = copy.deepcopy(value)
    return out


def observed_of(states, fills) -> dict:
    """把探路那一版的两张表**冻一份** → `{"states": [...], "fills": {...}}`。

    ⚠️ **深拷贝**：不深拷的话，改稿那双手改的是同一批对象，这份「证据」跟着一起变
    （那正是这一节要防的事，而且是**静默**的 —— 没有任何地方会响）。
    """
    return {"states": copy.deepcopy(list(states or [])),
            "fills": copy.deepcopy(dict(fills or {}))}


def card_fingerprint(card) -> tuple:
    """**整张卡**的指纹（`selectors` + 那几样锚的值）—— 「接受」拿它当失效判据（Task 6）。

    ⚠️ 与 `_selector_key` **不是一回事**，别混：
      · `_selector_key` 只比 `selectors` —— 它是**找路**用的（模型改了别的、地址没动，还找得回）；
      · `card_fingerprint` 比全部 —— 它是**判失效**用的（证据变了，人那次点头就不算数了）。
    """
    return _selector_key(card) + tuple(sorted(
        (key, _norm_card_value(card.get(key)))
        for key in ("label", "aria_label", "hint", "placeholder", "text")
        if _norm_card_value((card or {}).get(key))))


def _selector_key(card) -> tuple:
    """只比 `selectors`（去空白、排序）—— `find_observed` 第 ② 步找路用的那一把尺子。"""
    return tuple(sorted(str(s or "").strip() for s in ((card or {}).get("selectors") or [])
                        if str(s or "").strip()))


def _norm_card_value(value) -> str:
    return re.sub(r"\s+", " ", str(value or "")).strip().casefold()


def find_observed(observed, state_name: str, index: int, card) -> Optional[dict]:
    """当前这一步那张卡，**回原件里**找对应的那一步 → 原件那张卡（找不到给 `None`）。

    两步对法（顺序要紧）：
      ① 按 **(状态名, 组内步序)** —— 这是全仓既有的「这一步是谁」的把手
         （`_rule_i` 报的就是「组「X」第 N 步」，`_keep_repair_local` 也按它钉）；
      ② ① 落空 ⇒ 在原件**那一组**里按**卡的指纹**找一步（模型把两步调了个个儿、
         或在前面插了一步，都靠这一条救）。
    ③ 都落空 ⇒ `None` = **这一步没有可依的原始观察**（判据照这个如实说）。

    ⚠️ ② **不能作弊**：指纹必须命中**原件里真实存在**的一步 —— 编出来的卡在原件里找不到
    （`test_find_observed_returns_none_for_invented_card` 钉的就是这一条）。
    ⚠️ 这一层**只负责找**，不判级别 —— 级别是 `lint.address_basis` 的活（单一职责）。
    """
    if not isinstance(observed, dict):
        return None
    groups = observed.get("states")
    if not isinstance(groups, list):
        return None
    group = None
    for one in groups:
        if isinstance(one, dict) and str(one.get("name") or "") == str(state_name or ""):
            group = one
            break
    if group is None:
        return None
    steps = [s for s in (group.get("steps") or []) if isinstance(s, dict)]
    # ① 按步序
    if 0 <= index < len(steps):
        got = card_of(steps[index].get("target"))
        if got and _selector_key(got) == _selector_key(card):
            return got
        if not got and not _selector_key(card):
            return got                     # 两边都空 ⇒ 就是这一步（它本来就没 target）
    # ② 按地址的指纹（**只比 selectors** —— 模型改了别的、地址没动，照样找得回）
    want = _selector_key(card)
    if not want:
        return None
    for one in steps:
        got = card_of(one.get("target"))
        if got and _selector_key(got) == want:
            return got
    return None
```

### Task 3: 出处判据（纯函数 `lint.address_basis`）

> **开工前先读这段（2026-10-15 三处修正 —— 下面 Step 3 的逐字代码在这三点上是错的）**

    同一个字的两种排版写法算同一个字）。"""
    text = str(value or "").replace("’", "'").replace("‘", "'")
    return re.sub(r"\s+", " ", text).strip().casefold()


def assertions_of(selector) -> list:
    """一条选择器 → 它**断言了哪些事实**（`(种类, 值)` 的列表，保序去重）。

    只有这几类算断言（位置**不算** —— `:nth-of-type` / 结构组合子不主张任何身份，
    脆不脆是 `_fragile` 的活，两件事别混）：
      · `("attr", "name=email")` —— 属性名与值
      · `("id", "postcode-field")`
      · `("class", "btn")`
      · `("tag", "input")`
      · `("text", "Sign in")` —— 文字锚（产物重放认的那一套，见 `template._relocate`）
    """
    text = str(selector or "").strip()
    out: list = []
    m = _TEXT_ANCHOR.match(text)
    if m:
        return [("text", _norm_text(m.group(1)))]
    for attr, value in _ATTR_IN_SEL.findall(text):
        out.append(("attr", "%s=%s" % (attr.lower(), _norm_text(value))))
    for ident in _ID_IN_SEL.findall(text):
        out.append(("id", _norm_text(ident)))
    for cls in _CLASS_IN_SEL.findall(text):
        out.append(("class", _norm_text(cls)))
    for tag in _TAG_IN_SEL.findall(_ATTR_IN_SEL.sub(" ", _ID_IN_SEL.sub(" ", text))):
        out.append(("tag", _norm_text(tag)))
    seen, uniq = set(), []
    for one in out:
        if one not in seen:
            seen.add(one)
            uniq.append(one)
    return uniq


def _observed_facts_and_hint(card, observed_selector_text) -> tuple:
    """原始观察里**能当事实用**的那些（同一套拆法：把当时那几条选择器拆开，再加上卡上那几样）。

    ⚠️ 返回的是**二元组** `(facts, hint)`，不是光一个集合 —— `hint` 要单独拎出来降一档用
    （它把 `name` 与 `id` 合并了，见下面那段）。名字里带 `_and_hint` 就是为了不让读的人
    以为它只回一个集合（那会让 `DERIVED` 那两条分支永远走不到，而测试全绿）。
    """
    facts: set = set()
    for one in (observed_selector_text or []):
        facts.update(assertions_of(one))
    card = card or {}
    for key, kind in (("label", "text"), ("aria_label", "text"),
                      ("text", "text"), ("placeholder", "text")):
        if _norm_text(card.get(key)):
            facts.add((kind, _norm_text(card.get(key))))
    for one in (card.get("nearby_text") or []):
        if _norm_text(one):
            facts.add(("text", _norm_text(one)))
    #: `hint` 是 **`el.name || el.id`**（cdp 合并了，见下面那段）—— 两个属性都有可能，
    #: 所以它同时记成 `id` 与 `attr name=` 两条**线索**（级别由 `address_basis` 降一档）。
    hint = _norm_text(card.get("hint"))
    return facts, hint


def address_basis(selector, card, observed_selector_text) -> tuple:
    """这一根地址的**出处** → `(级别, 人话)`。

    三级（spec §3.2）：
      · `OBSERVED`    —— 每一条断言都能在原始观察里找到**同一个属性名 + 同一个值**；
      · `DERIVED`     —— 值观察过，但**属性名**只在同一来源的合法形式里二选一（今天只有 `hint` 这一族）；
      · `UNSUPPORTED` —— 有任何一条断言在原始观察里找不到依据。

    ⚠️ **文字只证明文字存在**：`nearby_text` / `text` / `label` 只能支持**文字锚**那一类断言
    （产物重放本来就认它），**不能**支持任何属性断言 —— 评审给的反例正是这一条：
    `nearby_text: "Choose your preferred plan"` ⇒ `input[name="preferred_plan"]`
    里的 `name` 从没观察过，值也是编的。
    ⚠️ 返回的「人话」是给**模型和人**读的（进 `Violation.message`）——说清缺哪一条依据。
    """
    asserts = assertions_of(selector)
    if not asserts:
        return OBSERVED, "这条地址**只说了位置、没主张任何身份**（位置不算断言）。"
    facts, hint = _observed_facts_and_hint(card, observed_selector_text)
    unknown, derived = [], []
    for one in asserts:
        if one in facts:
            continue
        # `hint` 那一族：值对得上 ⇒ 降一档（属性名二选一），不是「没依据」
        if hint and one[1] == hint and one[0] in ("id", "attr"):
            if one[0] == "attr" and not str(one[1]).startswith("name="):
                unknown.append(one)
            else:
                derived.append(one)
            continue
        if one[1] == hint and one[0] == "id":
            derived.append(one)
            continue
        unknown.append(one)
    if unknown:
        return UNSUPPORTED, ("这条地址里有**原始观察里没有的东西**：%s。"
                             "探路那一刻量到的只有：%s。"
                             % ("、".join("`%s`" % v for _, v in unknown[:4]),
                                "、".join("`%s`" % f for f in sorted(
                                    "%s:%s" % (k, v) for k, v in facts)[:6]) or "**什么都没有**"))
    if derived:
        return DERIVED, ("这条地址里的值是观察到的，但**属性名是二选一**（%s）："
                         "工具当时把 `name` 与 `id` 合并成一个 `hint` 报了（cdp 那边 `el.name || el.id`），"
                         "所以 `[name=…]` 与 `#…` 哪个是真的**没人验过**。"
                         % "、".join("`%s`" % v for _, v in derived[:4]))
    return OBSERVED, "每一条都回原始观察里对上了。"
```

    ★ 2026-10-15（spec §3.3a）：全靠 Derived 撑着的那一步**放行，但不当作「稳」**。

    而 Derived 的验证恰恰落在自测那一跳。所以这里只**记一笔**，让它带着标注往下走。

    from agent import fix
    states, fills = fix._literals(src)
    out: list = []
    for state in (states or []):
        if not isinstance(state, dict):
            continue
        name = str(state.get("name") or "?")
        for index, step in enumerate(state.get("steps") or []):
            if not isinstance(step, dict):

            target = step.get("target") or {}
            sels = _selectors(target)
            if not sels:

            card = fix.find_observed(observed, name, index, fix.card_of(target))
            if not card:

            if levels and all(one == DERIVED for one in levels):

                           "（值观察过、属性名二选一）—— **没人验过**，自测跑到它才算数。"

    return out

_ACCEPT_RE = re.compile(r"^接受地址\s+(\S+?)#(\d+)\s*$")


def _accept_from_note(state, note) -> dict:
    """人在闸上那句 `接受地址 组名#步序` → `addr_accepted` 里的一条。**认不出就不认**。

    ⚠️ 三条不许松（spec §3.5）：
      ① **只有人能写它** —— 这一格的唯一入口是`_enter` 收到的 `note`（模型碰不到）；
      ② **绑死四元组** —— 地址或卡的指纹一变，这条接受就失效（见 `_acceptance_holds`）；
      ③ **认不出不许猜** —— 写错一个字符就是没写（`test_a_mis_typed_note_is_not_an_acceptance`）。
    第 ③ 条为什么这么严：猜的后果是「人没同意的事被记成同意了」，而屏幕上一切正常。
    """
    m = _ACCEPT_RE.match(str(note or "").strip())
    if not m:
        return {}
    key = "%s#%d" % (m.group(1), int(m.group(2)))
    cand = (state.get("addr_candidates") or {}).get(key)
    if not isinstance(cand, dict) or not cand.get("selector"):
        return {}                       # 没有待接受的那一步 ⇒ 不认（也不编一条出来）
    one = {"state": m.group(1), "index": int(m.group(2)),
           "selector": cand["selector"], "card": cand.get("card") or ""}
    kept = [a for a in (state.get("addr_accepted") or []) if not _same_slot(a, one)]
    return {"addr_accepted": kept + [one]}


def _same_slot(a, b) -> bool:
    return (str(a.get("state")) == str(b.get("state"))
            and int(a.get("index") or 0) == int(b.get("index") or 0))

def _acceptance_holds(accepted, state_name, index, selector, card_fp) -> bool:
    """这一处现在还算被接受吗 —— **四元组逐项比**（spec §3.5「失效」）。

    ⚠️ 四样任一变了就 `False`：那根地址被改稿换了 / 原始观察重渲了（`card_fp` 变）/
    步序挪了 / 换了别的组。**失效 = 回到闸上重新问**，不是沿用上一次那声「行」。
    """
    for one in (accepted or []):
        if not isinstance(one, dict):
            continue
        if (str(one.get("state")) != str(state_name)
                or int(one.get("index") or 0) != int(index)):

        return (str(one.get("selector") or "") == str(selector or "")
                and str(one.get("card") or "") == str(card_fp or ""))

"""修站那一刀的两条回归子线：跑一遍新判据，把「错误新增」与「历史证据缺失」分开。

为什么要有这个工具（spec §5）：盘上交付过的产物**本来就缺证据**（click/scroll 带锚
09-28～10-12 全 0），所以新判据有理由在它们身上报 no-basis —— 那既不是回归，
也不能靠放宽新规则去消掉。分法就一句话：**看冻结那份里到底有没有那几样**。

用法（只读打开账本，绝不写）：
    python3 tools/addr_basis_report.py --ledger runtime/checkpoints.sqlite --limit 30
"""
from __future__ import annotations

import argparse
import collections
import sqlite3

import msgpack

from agent import fix, lint

#: 「有锚」的判据 = 卡上那几样里**至少一样有值**（与 `lint.address_basis` 用的同一组）
ANCHOR_KEYS = ("label", "aria_label", "hint", "placeholder", "nearby_text", "text")


def has_anchors(card) -> bool:
    return any((card or {}).get(k) not in (None, "", [], {}) for k in ANCHOR_KEYS)


def classify(src: str, observed) -> str:
    """这一份产物报出来的 no-basis，算**回归**还是**历史欠账**。

    ⚠️ 这是那条**硬线**的守门人：① 必须是 0；② 再长也不许把规则放宽（spec §5）。
    ⚠️ **2026-10-15 更正**：这里不再「按 `snippet` 反查是哪一步」（那个写得糙），改用**真生产者**
    `lint.no_basis_slots` —— 它产的就是判据自己认的那几处（带状态名、步序、那根地址、卡指纹），
    与 `_no_basis_say` 教人说的那句「接受地址 组名#步序」用的是**同一个把手**。
    """
    slots = lint.no_basis_slots(src, observed)
    if not slots:
        return ""
    for one in slots:
        # 报的那一步，在冻结那份里**有**锚 ⇒ 判据本可以给出路（却报了）= 回归
        if has_anchors(_card_at(observed, one.get("state"), int(one.get("index") or 0))):
            return "①错误新增"
    return "②历史证据缺失"


def _card_at(observed, state_name, index):
    """`(状态名, 组内步序)` → **原件那张卡**（认不出给 `{}` = 当作没证据）。

    ⚠️ 与判据那边**同一个把手**：`(状态名, 步序)` 是全仓既有的「这一步是谁」
    （`_keep_repair_local` 按它钉、`_no_basis_say` 按它报、`_accept_from_note` 按它认）。
    """
    for group in ((observed or {}).get("states") or []):
        if not isinstance(group, dict) or str(group.get("name") or "") != str(state_name or ""):
            continue
        steps = [s for s in (group.get("steps") or []) if isinstance(s, dict)]
        if 0 <= int(index) < len(steps):
            return fix.card_of(steps[int(index)].get("target"))
        return {}
    return {}


def _rows(ledger: str):
    """账本里每一趟的 `src` 与（有就给的）`observed`。**只读**。"""
    con = sqlite3.connect("file:%s?mode=ro" % ledger, uri=True)
    per = collections.defaultdict(dict)
    for tid, ch, ty, val in con.execute(
            "select thread_id, channel, type, value from writes"):
        if ch not in ("src", "observed", "states", "fills", "site", "end_reason"):
            continue
        data = msgpack.unpackb(val, raw=False, strict_map_key=False) if ty == "msgpack" else val
        per[tid].setdefault(ch, []).append(data)
    return per


def main(argv=None) -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--ledger", required=True)
    ap.add_argument("--limit", type=int, default=30)
    args = ap.parse_args(argv)
    buckets = collections.Counter()
    lines = []
    for tid, ch in sorted(_rows(args.ledger).items()):
        srcs = [s for s in (ch.get("src") or []) if isinstance(s, str) and s.strip()]
        if not srcs:
            continue
        # 老 job 没冻过 `observed` ⇒ 拿它**最早那一条** states/fills 重建（重建不出就如实记）
        observed = (ch.get("observed") or [None])[0]
        if observed is None:
            states = (ch.get("states") or [None])[0]
            fills = (ch.get("fills") or [None])[0]
            if states is None and fills is None:
                buckets["③没冻过也没账本"] += 1
                continue
            observed = fix.observed_of(states, fills)
        for src in srcs[-1:]:                       # 只看最后一版（交付的那一版）
            kind = classify(src, observed)
            if not kind:
                continue
            buckets[kind] += 1
            lines.append("%-22s %s  %s" % (tid, ch.get("site", [""])[0], kind))
    print("分账：%s" % dict(buckets))
    print("①错误新增**必须是 0**；②逐条列出来交人裁（不许为了让它们变绿而放宽规则）")
    for one in lines[:args.limit]:
        print("  " + one)
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```
