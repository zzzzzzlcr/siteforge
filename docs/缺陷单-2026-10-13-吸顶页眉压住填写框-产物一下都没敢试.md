# 缺陷单（2026-10-13）：`Your postcode` 填不进去 —— **吸顶页眉压住了它，产物于是「礼貌地」一下都没试**

**一句话**：填完上一格之后**站点自己滚动**，`#postcode` 的中心点正好停在**吸顶页眉**
（`div.h-full`，视口顶上那一条）底下 ⇒ 产物的遮挡纪律（「被盖着就不动手」）把
**两个声明地址 + 两个重找候选全部跳过**，一次 `cdp form` 都没发出去，
报文却只有一句「没找到「Your postcode」这个输入框，没填成」。

**代价**：那一单（`job-a6954761e657`）自测**三轮全死在这一步**，
三次诊断**全在改选择器**（因为报文说「没找到」），最后 `selftest_cap` 收场。

## 一、现场（8099 上那一单的三轮自测）

| | |
|---|---|
| job | `job-a6954761e657`（8099 / Bit 197；site `healthinsurancewatch`） |
| 症状 | 第 7 步 `form 'Your postcode'`、`ok=false`、`selector_used=""`、`fallback_level=null` |
| 报文 | 「没找到「Your postcode」这个输入框，没填成；页面没有变化」 |
| 重找记录 | `{"primary_selector": "#postcode", "resolved_by": "label+placeholder+nearby_text", "confidence": 1.0}` |

**时间戳（从截图文件 mtime 量的，这是本案最硬的一条证据）**：

| 轮次 | 第 7 步耗时 | 对照：第 8 步（重试填 age，成功） | 对照：第 9 步（再填 postcode，失败） |
|---|---|---|---|
| 第 1 轮 `034955` | **50.2 秒** | 13.6 秒 | 14.0 秒 |
| 第 2 轮 `035432` | **49.8 秒** | — | 14.7 秒 |
| 第 3 轮 `035959` | **50.1 秒** | 14.9 秒 | 14.5 秒 |

50 秒 = **35 秒空等**（`COVER_WAIT_SECONDS`）+ 常规开销（observe / 截图 / 重找 / 现场探针）。
第 9 步只花 14.5 秒，是因为那个遮挡物**已经进了「赖着不走」名单**（`_stuck_covers`），
第二次连等都不等 —— 两个数各自对得上，链条闭合。

**为什么当时拿不到真因**：产物只回一句**通用话术**（「找不到框 / 严格闸拒填 / 被盖着 /
位置不稳」四种共用一个句型），而 cdp 真正说了什么**只在产物的 stdout/stderr 里** ——
自测那条路跑完就把它们丢了（证据线那一趟是落盘的）。见下面「已修 · 丙」。

## 二、复现（8100 / Bit 222，真站，`_probe_hiw_cover.py`）

用**那一单自己的草稿**（从 8099 checkpoint 的 `src` channel 里取出来的原文）跑：
第一次**过**了（`cdp form 原话 sel='#postcode' … -> {"ok":true}`），第二次**复现**了失败，
形状与上面逐字相同：等 35 秒 → 两个声明地址 + 两个重找候选全跳过 → 同一句报文。

从外面每 0.5 秒量一次「`#postcode` 那个点上站着谁」：

```
{"why":"ok","at":"div.h-full","covers":[{"who":"div.h-full","rect":[0,0,360,98], …}]}
```

`[0,0,360,98]` = **视口顶上那一条**（页眉）。截图（`_hiw_cover.png`）里页面已经滚到底、
页眉之外**没有可见的蒙版** —— 它不是「加载没完」，是**站错地方了**。

## 三、根因

遮挡纪律本身是对的（2026-09-18 gowizard：点到盖着它的 consent 弹层上，cdp 照样回 ok，
那一步被记成做成了）。它错在**把两类遮挡当成了一类**：

- **加载蒙版**：等一等会走 —— 现有逻辑等 35 秒，对；
- **吸顶页眉 / 固定页脚**：等一辈子也不走，可它**只压住视口的那一条** ——
  **挪一下目标就躲开了**（人在那儿就是这么做的：往回滚一点，填）。

产物只会「等」和「放弃」，不会「挪」。

## 四、已修（2026-10-13，`agent/template.py`）

**甲、等的同时把它挪到视口正中**（有界）：

- 新增 `RECENTER_TRIES = 2` 与 `Filler._recenter(selector, frame_id)`：JS
  `scrollIntoView({block:'center'})`（**不动用 cdp** —— 生产重跑那条路不为此多起进程）；
- `_covered_by` 的等待循环里，每轮先 `_recenter` 一次（最多 2 次），再量、再等；
- **有界是关键**：真弹层挪不走 ⇒ 预算到点照旧不动手、照旧失败 ——
  这一刀改的是「有没有资格再看一眼」，**不是**「算不算盖着」（判据仍是 `_cover_once` 那一把尺子）。

**乙、报文分开**：这一步**一个候选都没试**（且原因是被盖着）时，不再说「没找到」，改说
「`div.h-full` 一直盖着「Your postcode」（等过、也把它往视口正中挪过，它没走）—— 这一下没敢填」。
（`Filler.cover_why` + `tried_any`：**试过、失败了**的那一支不许拿遮挡背锅。）

**丙、自测把产物自己的话落盘**（`agent/selftest.py`）：一遍跑完写
`<run_dir>/<遍名>/<site>.<遍名>.log`（stdout + stderr 原样）。这一条是本次排查最贵的那一格 ——
真因本来就在那几行里。落盘失败**不动结论**（旁路，不是判据）。
