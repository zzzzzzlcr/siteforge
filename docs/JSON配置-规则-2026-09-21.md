## 三、子步与两个标记

- **`optional`**：某一步标了它，那一步**失败不算这一趟失败**
  （判据散在 `:374 / :377 / :392 / :715`）。
- **`skip`**：`parsed.get("action") == "skip"`（`:638`）—— 模型那条路（AI 步）里用来
  表示「这一步跳过」。
- **嵌套 `steps`**：`if` / `quiz_loop` 这些分支里的子步在 `step["steps"]` 里
  （`:998 / :1045 / :1093 / :1137 / :1182`）。

## 四、★ 不认的动作会怎样（**这就是那道闸的理由**）

```python
# json_executor.py:3041
else:
    self.log.warning(f"[JSON] Unknown action: {action}")
    return False
```

**它不报错、不崩，只在日志里小声警告一句，就当这一步失败了，然后接着往下跑。**

⇒ 配置里打错一个动作名、或者模型**编一个新动作**出来，那份配置**照样跑得完**，
只是那一步什么都没做 —— 而它在屏幕上的样子，与「这一步没效果」**一模一样**。
这正是这个仓最贵的那类形状（「跑完了」与「跑对了」分不开）。
