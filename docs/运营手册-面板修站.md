# 运营手册：用面板修一个坏掉的站

这一份只讲**屏幕上点哪儿、填什么、看哪句话**。
（原理、实现、为什么这么设计：`docs/交接-2026-09-21-B线-4.md`。）

**你真正要管的只有三处**：左边的「运行」、下面的「今天哪些站在失败」、右下的「开一趟新的」。
中间那几栏是排障用的，第一遍可以完全不管。

---

## 0. 先记住一句话

面板替你把「开浏览器 → 走一遍 → 写脚本 → 真页面上验一遍」串起来。
**它不会替你做的那几件（只有你知道）**：

| 只有你知道的事 | 在哪填 |
|---|---|
| 哪个站坏了 | 「今天哪些站在失败」挑一个（或直接填站点名字查失败单） |
| **什么算成功** | 「开一趟新的」→「什么算成功」（走通之后页面上会出现哪段文字；**猜不得**） |
| 那个按钮/那一格长什么样 | 「开一趟新的」→「开工前先说一句」，或**每道闸上**底下那一行输入 |
| 表单要填什么值 | 「开一趟新的」→「表单数据」（可空；空着就用脚本自带的兜底值） |

---

## 1. 打开

浏览器进 `http://<跑服务那台机器>:8099/console`。
左边那一栏「运行」会列出这个服务记得的几趟活（服务重启过的话旧的就没了，带 `?job=<id>` 还能看）。

---

## 2. 四步

### 第 1 步：挑靶子

1. 左中「**今天哪些站在失败**」：日期不用改，按「**看榜单**」。
2. 它给你一行行站名，每行后面跟着人话：`失败 N 次 · 配置 X（启用/停用） · …`
   - **挑「启用」的那个**。停用的站在下一步会被门口挡住（读不到那份脚本 —— 而且这挡得对：
     停用的那份**可能不是它真正在跑的那份**）。要修停用的站，先去后端把它启用。
   - 失败次数多的优先，但那只是个提示：**榜单上很多行其实没坏**（偶发），这点下一步会替你判。
3. 想在那一栏里挑哪个站，用下面「**看哪个站的失败单**」→「**看这个站的失败单**」；
   或者直接在「这个站失败的那些趟」里填「站点名字」→「**查失败**」。

> 站点名字的写法：形如 `主机名/路径`（例：`goldenagesouls.com/land/sp/e7eacd5f`）。
> 从榜单上挑的话它自己会填。

### 第 2 步：开一趟

在「这个站失败的那些趟」里：

1. 「**要修哪一条**」下拉选一条 → 按「**照这条修**」。
   这一下会**自动填好**「开一趟新的」里三格：站点网址、失败证据、以及后端那个站点键 —— 你不用抄。
2. 回到「**开一趟新的**」，补齐剩下几格：

| 格子 | 怎么填 |
|---|---|
| 站点网址 | 上面自动带的，**别改**（改了服务会当你要修另一个站） |
| 这一趟要做什么 | 一句话，例：`把这一单走通：提交成功（URL 里出现 thank-you）` |
| **什么算成功** | 走通之后**页面上会印出来的那串文字**（例：`Thank you` / 中文 `提交成功`）。**只有你知道，系统不许猜**。⚠️ 它是拿这一格**整串**去**页面正文**里找（**中文英文都行、照抄即可**；**不分大小写** ✓），**不是找网址** ✗ —— 「URL 里出现 thank-you」这种写法不成立。⚠️ **只填那串字本身，前后别加说明**（真事两次：`出现文字 check your email` ✗、`出现Thank you.` ✗ —— 页面上只有 `Check your email` / `Thank you.` ⇒ 三趟探路都没认出来）；写错一两个字也一样，它会判「没到」并**自动重探 2 趟**（每趟真提交一遍），三趟都这样就停下来如实报 |
| 这是哪种活 | 选「**挂着的老站 —— 照一份失败证据修**」 |
| 开工前先说一句（可空） | **你知道就直接写**：那个按钮的选择器、那段 HTML、或一句人话（例：`点 a.btn（那个 Get A Free Quote）`）。它原样进模型这一次的提示词（不加工） |
| **这个站在后端是「停用」的，也照修** | 只在你要动一个**停用**的站时勾。默认不勾 = 服务在门口就拦（那份配置**可能不是生产在跑的那一份**）。勾了之后服务用 `type=debug` 把那一份（连源码）读回来当底稿，**并在每一道闸上写明「这一版的底稿来自停用那一份」** |
| **步骤表（可空，一行一步）** | **你知道顺序就写这儿**（这是最快的一条路）：一行一步，写「**动作 + 选择器 ｜ 等多久 ｜ 出现哪个元素才算这一步成了**」，例：`点 #cookiescript_accept ｜ 等 2-5 秒 ｜ 出现 #fname 才算这一步成了`。选择器不确定就写人话（「点那个 Accept all」），或用「页面现场」里的「**指它**」把工具算出来的选择器填进来 |
| 表单数据（可空） | 要喂给脚本的一段值（JSON）。空着 = 没给值，用脚本自带的兜底值 |
| 失败证据 | 自动带的 |

3. 按「**开一趟**」。

> 门口会先检查：缺「什么算成功」一类的问题会**当场弹回来**（它不会碰浏览器、不会跑模型、不写文件）。
> 弹回来的那段话下面列着缺什么，照着补就行。
>
> **为什么要写步骤表**（2026-09-21）：这条线原来难，难在**猜三件事** —— 点哪个元素 /
> 什么时候算好了 / 做成了没有。而这三件都是「人 + 工具」一句话能定死的：
> **你给顺序和「下一步的关键元素」，工具给选择器**（`cdp observe` + 「指它」）。定死之后：
> ① 失败能报「**第几步**没等到哪个元素」（老写法不认 `--trace`，这一行是唯一的定位）；
> ② 等待用**你给的区间**（30-50 秒）而不是模型自己拍一个固定值；
> ③ 站改版时你改那一行就行，不用重出整份稿。
> 步骤表**原样**进提示词（和「开工前先说一句」拼在同一个格子里发出去），服务那层不做加工。
>
> ★ 2026-09-22：**你写的那几句现在会进「探路」那一步**（新站那条路上唯一会思考的地方）。
> 在这之前它们只喂给「修站出补丁」那条路 ⇒ 新站的稿是**照账本算**出来的（账本里没有你写的字）——
> 屏幕上就是那句「我把步骤写得很细，它完全没按我的来」。现在探路按你的话走 ⇒ 账本记的就是你那套 ⇒
> 算出来的稿自然照它。⚠️ 稿仍是**算**出来的：步骤里如果有它表达不了的东西（特殊取值、分支），
> 那要走「修站」那条路（只有那条路会让模型动笔改源码）。

### 第 3 步：跟着走（每一道闸都做同一件事）

它每走到该你拿主意的地方就停下。**看三样、做一样**：

1. 看**这一道闸要做什么**（那一句人话）；
2. 看**摊开的事实**（那几格原始值 —— 尤其是「**给模型的证据**」与「**这一版改了什么**」）；
3. 看左中偏上的**那一趟活的状态**（`停下来了，在等你一句话`）。
4. 然后从底下那一行**三选一**：

| 按钮 | 干什么 | 什么时候用 |
|---|---|---|
| 「**继续**」 | 放它往前走一步 | 屏幕上的东西看着对 |
| 「**说一句，接着走**」 | 先把你写的那句话交给它，再往下走 | 要纠正它（`别点那个，点 a.btn`）或补一条信息 |
| 「**停下（撤不回）**」 | 停在这一步**之前**，这一步不会做 | 不想让它动那个站了 |

> 底下那一行**任何时候都能打字**，这句话会怎么到它手上**看那一行自己写的字**（页面不猜）：
> · 写「**直达**」= 它正在探路里跑，你按下的那句**进它的下一轮**（送到之后时间线上会出现一条
>   「交给它了」）—— 2026-09-22 起这是默认（开关 `STEER_WIRED`）；
> · 写「**排队**」= 它现在不在探路里跑（在写稿 / 自测 / 停在闸上），这句先记下、到下一道闸
>   预填进输入框，你按一下才送过去。
> 两种都**不自动发**：最后一下永远是你按的。

### 第 4 步：收工

最后一道闸过完，脚本就写进 `forms/sites/<短名>.py`。屏幕上会说它落在哪儿。
那之前**自测**会往站方**真提交**（一单 = 一笔真实流量）。

## 3. 每道闸上该看什么

| 闸（屏幕上那句） | 你要看的 | 通常怎么做 |
|---|---|---|
| 开工前的确认 | 站点网址 / 目标 / **成功判据** 对不对 | 对就「继续」 |
| 打开浏览器探路（修站这条路**不重新探路**） | 「**给模型的证据（旧脚本停在哪儿）**」—— 旧脚本跑到哪儿停的、它自己打了什么 | 「继续」；你看出该点哪个就直接「说一句」 |
| 写这一版 py | 「第几版」+ 上一闸那份证据（这一步**会叫模型**，几秒） | 「继续」 |
| 检查这一版有没有手拼 JS | 有没有被打回、打回原因 | 「继续」 |
| **在真浏览器上按扰动序列自测** | 「**这一版改了什么**」（diff）—— **这一版到底是哪几行变了** | 不对就「说一句」纠正；对就「继续」（这一步之后它会真提交） |
| 把它写进站点目录 | 「这一版改了什么」+ 落在哪个文件 | 「继续」 |

右侧「**页面现场**」这一栏**每道闸都值得扫一眼**：它摆的是跑证据那一趟**跑完现读那一页**的结果 ——
两边都列着：**「它自己收到的那几个」**（读到了、它没用）与**「页面上有、它却没收到」**的那几条
（连着 HTML 和 href）。

**每一条后面都有一个「指它」** —— 看见哪一条是「该点的那个」，点它一下：那一行会
「原样变成一句话」填进底下的输入框（`要点的那个是页面上这一条：<button>Accept all</button>`）。
它只填、不替你发 —— 你还能改、能续写（比如后面补一句「先点它再往下走」），
然后自己按「说一句，接着走」。

> ★ **页面上挡着什么**那一行（`cdp observe` 的 `obstructions`）值得先看：它挡着的时候，
> 点在别处的点击**会被它吃掉**，屏幕上就成了「做了、页面没动」。那一行会直接给你
> **点掉它该点哪个地址**，也有「指它」—— 点一下把那个地址拼成一句话填进输入框，
> 你补一句「第一步先点它」再发出去，比让模型自己猜准得多。
>
> ★ 2026-09-21 真事（那一站第一次没修成的根因）：页面上一根 **cookie 横幅**盖着整页
> （`Accept all` / `Decline all`）。脚本**读到了**它、**没点** ⇒ 后面每一步的点击都被那层浮层
> 吃掉 ⇒ 屏幕上就成了「**每一步都做成了，但页面没动**」。这就是为什么这一栏把「它收到的」
> 也摆出来、也带「指它」：**该点的不一定在「漏掉」那一边**。
> ⚠️ 而且**生产那边不一定有那个 cookie**（我手动点掉只是本机这个窗口）—— 所以这种「先点掉横幅」
> 的那一步**必须写进脚本**，别指望浏览器记着。

## 4. 屏幕上那些栏目（谁常用、谁排障用）

| 栏目 | 干什么 | 常用吗 |
|---|---|---|
| 左栏「运行」 | 挑一趟活来看（可点） | 常用 |
| 今天哪些站在失败 | 榜单：哪天、哪些站在失败 | 常用 |
| 这个站失败的那些趟 | 查某个站的失败单 → 「照这条修」一键带料 | 常用 |
| 开一趟新的 | 发起修复 | 常用 |
| **时间线** | 它做了什么、说了什么，按顺序（新的在下面） | 常用（卡住时看这里） |
| 轮次与截图 | 每一轮的闸拍小图、那一轮的账 | 偶尔 |
| **页面现场** | 脚本收到了什么 + 页面上它没收到的 | 常用 |
| 这个窗口 | 这一趟用的那个真浏览器（去看/重开/关掉） | 偶尔 |
| 这一单为什么失败 | 从日志原文里定位那一单卡在哪 | 排障 |
| 这份 JSON 配置差在哪一格 / 这份配置执行器认不认 | **读**：看 JSON 配置差在哪、执行器认不认（**不写**，这一栏自己不碰后端）；写回在同栏的「预检写回 / 确认写回」两下 | 排障 / 改 JSON 站 |
| 底下一行 + 三个按钮 | 你的回话 | 常按 |

> ⚠️ 按「预检写回」会**往那个站真跑一遍页面（一次真实提交）** —— 跟自测那一步同一件事，
> 别拿正在跑的站乱按。
>
> JSON 配置支持安全写回：先读取并编辑整份配置，填写可追溯的确认人，点“预检写回”。
> 服务会强制做执行器合规检查和真页面复跑；两道闸都通过后才会启用“确认写回”。
> 写入前会再次读取防止覆盖别人的新修改，写后会回读核对，并保存原配置备份。
> 当前只更新已经存在的 JSON 配置；“没有就创建”的分支尚未做生产实测，因此不会开放。

## 5. 出岔子时对着这话找

| 屏幕上那句话 | 什么意思 | 你怎么办 |
|---|---|---|
| `这份开场白还开不了工（没有碰浏览器、没有跑模型、没有写任何文件）` + 几条 | 门口就挡了，缺的几项列在下面 | 照着补齐再按「开一趟」 |
| `读不了这个站的脚本：这份配置在，但后端把它标成「停用」` | 那个站在后端是停用的（服务默认不碰停用那份：它**可能不是生产在跑的那一份**） | 两条路：① 在「开一趟」那一栏勾上「**这个站在后端是「停用」的，也照修**」——服务就把 `type=debug` 那一份读回来当底稿（闸上写明底稿来源）；② 换一个启用着的站 |
| 屏幕上一片红：`没这个任务：job-…` + 控制台一串 404 | 地址里带的那个 job **不在这个服务里了**（那张表在内存里，服务重启过就没了） | 把地址里 `?job=…` 那一截去掉，或者从左边「运行」栏挑一趟 |

> **停用 ≠ 没在跑**：配置停用的站照样在失败（量过：`japansdates` 一天 6 条）。
> 所以「要不要动一个停用的站」是**你**的决定（那一格勾不勾）—— 服务把它记在闸上，不替你选。
| `这个站从 … 起没有失败的记录` | 量到了、真没有 —— ⚠️ 但「查哪一段」**默认只查今天**，而站上的失败常常不是今天的（实测：那个站的失败全在 9-17） | 把「查哪一段」挑成**「近 7 天 / 近 30 天」**再查；再没有就换站 |
| `跑了一遍线上那份旧脚本…**它自己就走通了**（退出码 0）` | **这个站没坏**（榜上那一行是偶发） | 这一趟就此停住 —— **别修**。它偶尔挂的话，先说清「在什么条件下挂」 |
| `跑不了一遍拿证据：没有可用的窗口或表单数据` | 缺窗口那根线 | 看右栏「这个窗口」（没了就「重开窗口，接着走」） |
| `开不了这一趟：服务自己去开窗口**没成**` + 外面那句话 | 同上，但这是**服务在门口就挡下了**（2026-09-22 起）：它没开 job、没碰浏览器、没花钱 —— 外面那层窗口服务晃了一下（「浏览器正在打开中」/ 超时） | **等几秒再按一次「开一趟」**；连着几趟都开不出来就是 bit 那头的事 |
| `探不了路：这一趟**没有窗口**` | 同上的另一种落点：这一趟**已经开出去了**才发现没窗口（老 job 或调用方**没给**窗口、外面又开不出来） | 「重新来一遍」或**再发起一趟**；这一趟没开浏览器、没跑模型、页面与文件都是原样 |
| `⚠️ 页面上有、它却没收到` | 脚本漏了那几个东西 | 在底下「说一句」里写清要点的那个（选择器 / 那段 HTML / 一句人话） |
| `这一版改了什么` 里只有空格/一处没改 | 这一版没真的改东西 | 「说一句」说清改哪儿，让它重出（它会重试） |
| `窗口没了` | 那个浏览器死了 | 按「重开窗口，接着走」（从停下的地方接着跑） |
| `停在 … 等你说` | 到闸了 | 看那一闸的事实，然后继续 / 说一句 |

## 6. 最快的标准流程（六步 —— 照这个走，别自己发明）

> 这一节是 2026-09-22 在 `qualify.lastingpowerofattorney.io` 那一站**真跑通**的那一套：
> 六屏的漏斗，一次修成、自测一遍过、落盘。**它为什么快**：把「猜三件事」换成了
> 「人给顺序 + 工具给元素」—— 猜该点哪个元素、猜什么时候算好了、猜做成了没有，这三件
> 原来全靠模型赌，现在一件都不用赌了。

**第 0 步 · 先看页面现场（不是先开跑）**
在面板上把站和那一单挑好（「查哪一段」选够宽，比如近 30 天）→ 按「照这条修」把表填上。
**每一道闸**右边「**页面现场**」那一栏都值得扫一眼：它摆的是**跑完现读那一页**的结果 ——
脚本自己收到了什么、「页面上有、它却没收到」的、以及**页面上挡着什么**（带「点掉它该点哪个地址」）。

**第 1 步 · 把元素量准**（这一步是整个流程里最值钱的一步，别跳）
在那一页上把每个要动的元素找出来，**优先选稳定的**：

| 什么算稳定 | 例子 | 能用吗 |
|---|---|---|
| `id`（固定字符串） | `#cookiescript_accept` | ✅ 最好 |
| `placeholder` / 问句文字 | `input[placeholder="e.g. RG24 8PE"]`、`点文字「Health and Welfare」` | ✅ 好 |
| `type` 那一类 | `input[type=email]` | ✅ 可以（配合 placeholder 更稳） |
| **渲染时生成的 id** | `#option-1758090197578`（`1758090197` 是 epoch 毫秒） | ❌ **每次渲染都变**，写进步骤表等于没写 |
| `class`（Tailwind 那一串） | `class="inline-flex shrink-0 …"` | ⚠️ 少用（换版本就变） |

⚠️ **每一屏都有一个隐形输入框 `name="company_url"` 之类 —— 那是蜜罐，绝对不许填**
（填了那一单会被判成机器人）。「页面现场」里工具的读数会把它列在 `honeypots` 里。

**第 2 步 · 填「步骤表」**（一行一步：**动作 + 选择器 ｜ 等多久 ｜ 出现哪个元素才算这一步成了**）
```
点 #cookiescript_accept ｜ 等 2-5 秒 ｜ 复读：#cookiescript_injected_wrapper 不在页面上才算清掉
点文字「Myself」（Progress 30%）｜ 等 1-3 秒 ｜ 出现「What kind of Lasting Power of Attorney」
点文字「Health and Welfare」（Progress 42%）｜ 等 1-3 秒 ｜ 出现「What is your postcode」
填 input[placeholder="e.g. RG24 8PE"]，再点「Continue」｜ 等 1-3 秒 ｜ 出现「Who should we send the free quote to」
填 input[placeholder="Enter your full name"]，再点「Continue」｜ 等 1-3 秒 ｜ 出现「What is your email address」
填 input[type=email][placeholder="Enter email address"]，再点「Continue」｜ 等 1-3 秒 ｜ 出现「Where can we send your quote」
填 input[type=tel][placeholder="Enter mobile number"]，再点文字「Get Results」（这一步就是提交）｜ 等 30-50 秒 ｜ 出现成功文案
```
三件事必须写进去（缺一件就会白跑一趟）：
- **等多久**：写**区间**（`2-5 秒` / `30-50 秒`）。异步注入的东西（同意横幅那种）**要等它出现**，
  不能一开跑就点；提交之后要给它**几十秒**，别拿固定 2 秒去催。
- **出现哪个元素才算这一步成了**：这就是判据。没有它，脚本只能「做了就算成了」，
  而「做了、页面没动」正是最常见的那一类失败。
- **选择器不确定就写人话**（「点那个 Accept all」）——比猜一个错的选择器好；
  也可以用「页面现场」里的「**指它**」把工具算出来的选择器填进来。

**第 3 步 · 开一趟**：把「什么算成功」填上（**只有你知道**：走通之后页面上会出现的那串字，
比如 `Thank you` —— **页面上真印着的那几个字**，中文站就抄中文）；那是个停用的站就勾上「停用也照修」；按「开一趟」。

**第 4 步 · 跟着闸走**：每道闸看三样 —— 「这一版改了什么」（它是不是照你的表改的）、
「页面现场」（有没有东西挡着 / 有没有蜜罐）、「给模型的证据（旧脚本停在哪儿）」。
不对就在底下「说一句」告诉它，别让它自己猜。

**第 5 步 · 自测**：真浏览器、按扰动序列跑，**最多 3 次真提交**。过了之后看它自己那份 trace：
应该**逐条对上你的步骤表**（`第 0 步 清 cookie 横幅：已复读确认不在`、`第 1 步 …`），
最后一条是成功那一页。**对不上就是没按你的表走**，回第 4 步说一句。

**第 6 步 · 上线（面板上三下）**
修好的那份 py 落在仓库 `forms/sites/<站名>.py`；**生产是从后台按接口下载的**，
所以上线 = **把它上传到后台**。面板底下那一栏「**把这一趟修好的脚本传到后台**」就是干这个的，
而且**只按这一趟**（不用你填站名/键 —— 你手打一个键打错，就是**悄悄传到别的站**）：

1. 填一下「**谁确认的**」（后端要的审计字段，写姓名或值班号）；
2. 按「**预检上传**」—— **这一下绝不写**：它把「本地那份多少字节 / 哪个 sha」与
   「后端**现在**那份的 sha」摆出来给你看，然后发一张 10 分钟就过期的**一次性票**；
   ⚠️ 如果后端那份**已经**是本地这份，它会直接说「已经是这一份了，不用传」；
3. 按「**确认上传**」—— 这一下才真写。写之前它会**先比一次**（预检之后有没有别人改过？
   改过就拒，不硬压），写完**自己再读一遍**：sha 与本地对得上才算成功；
   **对不上它会立刻把原来那份传回去**，并把「回滚成没成」如实说出来。
4. 万一要退回去：按「**回滚到上传前**」（它先核对「后端现在是不是我们传上去的那一份」，
   不是就拒绝覆盖）。

⚠️ 两条别记错：
- **判据是「回读一致」，不是接口回 200**；
- **上传 = 换掉 + 启用**（2026-09-22 起）：写的时候带着 `status: 1` ⇒ 传上去它就会真跑
  （⚠️ 那一行若本来是**被人停用**的，这一下会把它**重新启用** —— 心里有数再按「确认上传」）。

> ⚠️ **别拿一个真在赚钱的站当练手场**：整条路上有两次真流量 —— 证据那一趟提交一次、
> 自测那一趟最多 3 次。先在能接受的站上把步骤表跑顺。

## 7. 三条规矩

1. **它正在跑的时候，别去动那个窗口的鼠标键盘。** 两边一起动，动作会落到别处，
   而失败会被记成**脚本的问题**。想动手就等它停在闸上（那才是你的时刻）——
   而且你动过页面之后，用「说一句」告诉它，别让它自己猜。
2. 「**停下**」是撤不回的：停下了就是停下了（那一步不会做，页面与文件都保持原样）。
3. 自测那一关会往站方**真提交**（每趟最多 3 次）—— 别拿一个真在赚钱的站乱试。

## 8. 换「花钱那把 key」（模型）—— 想单独计费时

钱是**模型那把 key** 花的（`OPENAI_API_KEY`）。它只在**服务进程的环境**里、**不落任何文件**，
所以换它就是「改环境 + **重启服务**」。默认不填的还有两格：`OPENAI_BASE_URL`
（默认 `https://api.deepseek.com`）、`SPIKE_MODEL`（默认 `deepseek-v4-flash`）。

```bash
# 1) 把新 key 放进这个 shell 的环境（不回显、不进 history）
read -rs OPENAI_API_KEY && export OPENAI_API_KEY

# 2) 重启服务 —— 值从上面那个环境里取（不进 argv、不进 ps、不进 shell 历史）
cd /company/siteforge
.venv/bin/python tools/relaunch-svc.py "$(pgrep -f 'uvicorn agent.service' | head -1)" OPENAI_API_KEY

# 3) 核对换成了没有：比**指纹**（值不用打出来）
printf '%s' "$OPENAI_API_KEY" | sha256sum | cut -c1-12
#    与第 2 步打出来的 OPENAI_API_KEY 那 12 位一致 = 换成了
```

- 换**线路**再加一格 `OPENAI_BASE_URL`；换**模型**加 `SPIKE_MODEL`（两个都写在同一条命令后面）。
  本机现在用的是 `SPIKE_MODEL=deepseek-chat`（量过：那个模型 4 秒 / 583 token；
  `deepseek-v4-flash` 会把预算耗在思考上、`content` 回空 ✗）。
- 撤掉某次试验留下的旋钮：那个变量名前**加个减号**（例：`-SPIKE_MAX_TOKENS`）。
- ⚠️ **重启会把正在跑的那一趟弄没**（状态只在内存里）⇒ 等面板上没有活在跑再重启。
- ⚠️ **别把 key 打进命令行、别贴进对话**（命令行会进 shell 历史，`ps` 也看得见）—— 用 `read -rs`。
- 忘了配的话不用担心它乱借：模型那一步会当场报一句人话（说清该在哪儿配、怎么核对）✗ 不会去别处找 key。

### 8.1 想让模型走**内网网关**（计费走它）

那个网关（`https://llm.3tkj.cn`）**同时提供 Anthropic 与 OpenAI 两种端点**
（`/v1/models` 里写着 `supported_endpoint_types: ["anthropic","openai"]`），而 siteforge 走
OpenAI 协议 ⇒ **三格一起换**，代码一行都不用动：

```bash
read -rs OPENAI_API_KEY && export OPENAI_API_KEY     # 网关那把（就是 env 里那串 ANTHROPIC_AUTH_TOKEN）
cd /company/siteforge
.venv/bin/python tools/relaunch-svc.py "$(pgrep -f 'uvicorn agent.service' | head -1)" \
    OPENAI_API_KEY 'OPENAI_BASE_URL=https://llm.3tkj.cn/v1' 'SPIKE_MODEL=deepseek-v4-pro'
```

⚠️ **模型名要换成网关认识的那几个** —— 只换 base 不换模型名会当场报「模型不存在」✗。
网关上有 6 个（2026-09-22 量的）：`deepseek-v4-flash`（**本机现在用它**）、`deepseek-flash`、
`deepseek-v4-pro`、`claude-sonnet-4-6`、`claude-opus-5`、`claude-haiku-4-5-20251001`。
⚠️ **`deepseek-chat` 在这个网关上跑不了** ✗（量过：`503 model_not_found — No available channel for
model deepseek-chat`）—— 那是网关**没给它配上游通道**；要用它就得直连 `https://api.deepseek.com`
（撤掉 `OPENAI_BASE_URL`）并用你自己的 DeepSeek key。
⚠️ **换模型就是换行为**（速度、出稿质量、每单花的钱都会变）—— 换了之后头几趟多看一眼闸上的稿。
⚠️ 网关回执里带 `billing_usage.source` ⇒ 计费确实落在网关那边 ✓；
   `FMR_AGENT_TOKEN` / `FORM_SCRIPT_WRITE_TOKEN` 与模型那把**是两回事**，不受影响 ✓。

#### 8.1.1 量过的两件事（2026-09-22，**按生产预算** max_tokens=12000）

| 模型 | 一次「小活」（给一段代码、要一段补丁） | 结论 |
|---|---|---|
| `deepseek-v4-flash` | **32.3s**，content 330 字，completion **7370**（其中**思考 7277**） | 能用 ✓，但**思考极重** |
| `deepseek-flash` | 29.9s，content 327 字，completion 7346（思考 7254） | 同上（两个名字表现几乎一样） |
| `deepseek-v4-pro` | ✗ **504 Gateway Time-out**（nginx —— 带大预算那次它自己超时） | 大预算下**不如 flash 稳** |

⇒ **`SPIKE_MAX_TOKENS` 千万别调小**：拿 `max_tokens=16 / 256` 试的时候，flash 的 `content`
**直接回空** ✗（思考先把预算吃光了 —— 仓里那条「v4-flash 思考吃满、content 回空」就是这么来的）。
默认 12000 是保命的；flash 便宜省在**单价**上，不是省 token 数。


## 9. 换代理国家（面板上那一格）

面板上有一栏「**换个代理国家**」：填两个字母（`US` / `CA` …）、按一下「换成这个国家」。
它换的是**这台机器上 agent 那条出口链**（宿主 `:1081`）——
**生产那条（`:1080`）一个字都不动**（那条是单例热换的，碰了会把正在跑的生产任务一起换掉，
2026-09-14 实测过）。

判据是「**核到了**」：换完它经 `:1081` 问一句「这个出口是哪国」，问到的**就是**要的那个
才说「换成 X 了」；问不到会说「**没换成**」+ 它自己的原话 —— **它不会说换好了**。
所以别看那一行绿不绿，看它说的话里有没有「**核过**」。

- ⚠️ **它正在跑的时候按不动**（服务会拦，409 一句话）：换链要把 gost 重启，
  那一趟正用着的连接会被掐断。等它停下来（停在闸上 / 跑完）再按。
- ⚠️ **「问不出来」≠「没换」**（`:1081` 那个实例没在跑时就是这样）—— 那句话里写着这一条。
- ⚠️ 「现在这个出口」那一行是**实测读数**：开页问一次、按完再问一次；
  它**不跟着每 3 秒的重画重问**（问一次要经 gost 打一次外网，挂上去就是白烧一条出口）。
- ⚠️ 你按过哪个国家，**这一趟服务的自测第 5 遍**（「换个代理国家再跑一遍」）就有了旋钮 ——
  那一遍会**真去换链 + 再跑一遍产物**（= 一次提交）。没按过则照旧跳过（默认允许跳过它）。

换不动时对着查（都在**宿主**上看，四条都是只读）：

```bash
pgrep -a gost | grep 1081                               # :1081 那个实例在不在
cat /opt/skills/auto-farm-skill/config/gost1081.chain   # 链文件（两行：jumper + 出口）
tail -5 /opt/skills/auto-farm-skill/logs/gost-watch.log # watcher 有没有读到变化
/company/siteforge/.venv/bin/python /company/siteforge/tools/set-country.py --show  # 现在哪国
```

⚠️ 这一格**只动 `:1081`**：那条链是**实验/agent 专用**的（见仓里 `skills/bit-window/SKILL.md`
那张表）。要确认没碰到生产：`pgrep -a gost` 里 `-L socks5://0.0.0.0:1080` 那一条的 pid
与链**都不该变**。
