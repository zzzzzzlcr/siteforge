# 运营手册：用面板修一个坏掉的站

这一份只讲**屏幕上点哪儿、填什么、看哪句话**。
（原理、实现、为什么这么设计：`docs/交接-2026-09-21-B线-4.md`。）

**你真正要管的只有三处**：左边的「运行」、下面的「今天哪些站在失败」、右下的「开一趟新的」。
中间那几栏是排障用的，第一遍可以完全不管。

---

## 0. 先记住一句话

面板替你把「开浏览器 → 走一遍 → 写脚本 → 真页面上验一遍」串起来。
**它不会替你做的那几件（只有你知道）**：

| 只有你知道的事 | 在哪填 |
|---|---|
| 哪个站坏了 | 「今天哪些站在失败」挑一个（或直接填站点名字查失败单） |
| **什么算成功** | 「开一趟新的」→「什么算成功」（走通之后页面上会出现哪段文字；**猜不得**） |
| 那个按钮/那一格长什么样 | 「开一趟新的」→「开工前先说一句」，或**每道闸上**底下那一行输入 |
| 表单要填什么值 | 「开一趟新的」→「表单数据」（可空；空着就用脚本自带的兜底值） |

---

## 1. 打开

浏览器进 `http://<跑服务那台机器>:8099/console`。
左边那一栏「运行」会列出这个服务记得的几趟活（服务重启过的话旧的就没了，带 `?job=<id>` 还能看）。

---

## 2. 四步

### 第 1 步：挑靶子

1. 左中「**今天哪些站在失败**」：日期不用改，按「**看榜单**」。
2. 它给你一行行站名，每行后面跟着人话：`失败 N 次 · 配置 X（启用/停用） · …`
   - **挑「启用」的那个**。停用的站在下一步会被门口挡住（读不到那份脚本 —— 而且这挡得对：
     停用的那份**可能不是它真正在跑的那份**）。要修停用的站，先去后端把它启用。
   - 失败次数多的优先，但那只是个提示：**榜单上很多行其实没坏**（偶发），这点下一步会替你判。
3. 想在那一栏里挑哪个站，用下面「**看哪个站的失败单**」→「**看这个站的失败单**」；
   或者直接在「这个站失败的那些趟」里填「站点名字」→「**查失败**」。

> 站点名字的写法：形如 `主机名/路径`（例：`goldenagesouls.com/land/sp/e7eacd5f`）。
> 从榜单上挑的话它自己会填。

### 第 2 步：开一趟

在「这个站失败的那些趟」里：

1. 「**要修哪一条**」下拉选一条 → 按「**照这条修**」。
   这一下会**自动填好**「开一趟新的」里三格：站点网址、失败证据、以及后端那个站点键 —— 你不用抄。
2. 回到「**开一趟新的**」，补齐剩下几格：

| 格子 | 怎么填 |
|---|---|
| 站点网址 | 上面自动带的，**别改**（改了服务会当你要修另一个站） |
| 这一趟要做什么 | 一句话，例：`把这一单走通：提交成功（URL 里出现 thank-you）` |
| **什么算成功** | 走通之后页面上会出现的**那串文字**（例：`thank-you`）。**只有你知道，系统不许猜** |
| 这是哪种活 | 选「**挂着的老站 —— 照一份失败证据修**」 |
| 开工前先说一句（可空） | **你知道就直接写**：那个按钮的选择器、那段 HTML、或一句人话（例：`点 a.btn（那个 Get A Free Quote）`）。它原样进模型这一次的提示词（不加工） |
| 表单数据（可空） | 要喂给脚本的一段值（JSON）。空着 = 没给值，用脚本自带的兜底值 |
| 失败证据 | 自动带的 |

3. 按「**开一趟**」。

> 门口会先检查：缺「什么算成功」一类的问题会**当场弹回来**（它不会碰浏览器、不会跑模型、不写文件）。
> 弹回来的那段话下面列着缺什么，照着补就行。

### 第 3 步：跟着走（每一道闸都做同一件事）

它每走到该你拿主意的地方就停下。**看三样、做一样**：

1. 看**这一道闸要做什么**（那一句人话）；
2. 看**摊开的事实**（那几格原始值 —— 尤其是「**给模型的证据**」与「**这一版改了什么**」）；
3. 看左中偏上的**那一趟活的状态**（`停下来了，在等你一句话`）。
4. 然后从底下那一行**三选一**：

| 按钮 | 干什么 | 什么时候用 |
|---|---|---|
| 「**继续**」 | 放它往前走一步 | 屏幕上的东西看着对 |
| 「**说一句，接着走**」 | 先把你写的那句话交给它，再往下走 | 要纠正它（`别点那个，点 a.btn`）或补一条信息 |
| 「**停下（撤不回）**」 | 停在这一步**之前**，这一步不会做 | 不想让它动那个站了 |

> 底下那一行**任何时候都能打字**：它跑到一半你写的字会**排队**，到下一道闸时预填进输入框 ——
> 但它**不会自动发**，最后一下永远是你按的。

### 第 4 步：收工

最后一道闸过完，脚本就写进 `forms/sites/<短名>.py`。屏幕上会说它落在哪儿。
那之前**自测**会往站方**真提交**（一单 = 一笔真实流量）。

---

## 3. 每道闸上该看什么

| 闸（屏幕上那句） | 你要看的 | 通常怎么做 |
|---|---|---|
| 开工前的确认 | 站点网址 / 目标 / **成功判据** 对不对 | 对就「继续」 |
| 打开浏览器探路（修站这条路**不重新探路**） | 「**给模型的证据（旧脚本停在哪儿）**」—— 旧脚本跑到哪儿停的、它自己打了什么 | 「继续」；你看出该点哪个就直接「说一句」 |
| 写这一版 py | 「第几版」+ 上一闸那份证据（这一步**会叫模型**，几秒） | 「继续」 |
| 检查这一版有没有手拼 JS | 有没有被打回、打回原因 | 「继续」 |
| **在真浏览器上按扰动序列自测** | 「**这一版改了什么**」（diff）—— **这一版到底是哪几行变了** | 不对就「说一句」纠正；对就「继续」（这一步之后它会真提交） |
| 把它写进站点目录 | 「这一版改了什么」+ 落在哪个文件 | 「继续」 |

右侧「**页面现场**」这一栏**每道闸都值得扫一眼**：它摆的是跑证据那一趟**跑完现读那一页**的结果 ——
脚本自己收到了几个可点元素，以及**「页面上有、它却没收到」**的那几条（连着 HTML 和 href）。
**那几条通常就是你要指给它的东西**：把其中一条写进「说一句」里（`点 a.btn`）。

## 4. 屏幕上那些栏目（谁常用、谁排障用）

| 栏目 | 干什么 | 常用吗 |
|---|---|---|
| 左栏「运行」 | 挑一趟活来看（可点） | 常用 |
| 今天哪些站在失败 | 榜单：哪天、哪些站在失败 | 常用 |
| 这个站失败的那些趟 | 查某个站的失败单 → 「照这条修」一键带料 | 常用 |
| 开一趟新的 | 发起修复 | 常用 |
| **时间线** | 它做了什么、说了什么，按顺序（新的在下面） | 常用（卡住时看这里） |
| 轮次与截图 | 每一轮的闸拍小图、那一轮的账 | 偶尔 |
| **页面现场** | 脚本收到了什么 + 页面上它没收到的 | 常用 |
| 这个窗口 | 这一趟用的那个真浏览器（去看/重开/关掉） | 偶尔 |
| 这一单为什么失败 | 从日志原文里定位那一单卡在哪 | 排障 |
| 这份 JSON 配置差在哪一格 / 这份配置执行器认不认 | **只读**：看 JSON 配置差在哪、执行器认不认 | 排障 |
| 底下一行 + 三个按钮 | 你的回话 | 常按 |

> ⚠️ 这两个「JSON 配置」栏**只读不写回**，所以**现在能用面板修的是 py 脚本**；
> JSON 站的写回还没做。

## 5. 出岔子时对着这话找

| 屏幕上那句话 | 什么意思 | 你怎么办 |
|---|---|---|
| `这份开场白还开不了工（没有碰浏览器、没有跑模型、没有写任何文件）` + 几条 | 门口就挡了，缺的几项列在下面 | 照着补齐再按「开一趟」 |
| `读不了这个站的脚本：这份配置在，但后端把它标成「停用」` | 那个站在后端是停用的 | 去后端启用它（或换一个启用的站） |
| 屏幕上一片红：`没这个任务：job-…` + 控制台一串 404 | 地址里带的那个 job **不在这个服务里了**（那张表在内存里，服务重启过就没了） | 把地址里 `?job=…` 那一截去掉，或者从左边「运行」栏挑一趟 |
| `这个站从 … 起没有失败的记录` | 量到了、真没有 | 把时间窗放大（改「查哪一段」）或换站 |
| `跑了一遍线上那份旧脚本…**它自己就走通了**（退出码 0）` | **这个站没坏**（榜上那一行是偶发） | 这一趟就此停住 —— **别修**。它偶尔挂的话，先说清「在什么条件下挂」 |
| `跑不了一遍拿证据：没有可用的窗口或表单数据` | 缺窗口那根线 | 看右栏「这个窗口」（没了就「重开窗口，接着走」） |
| `⚠️ 页面上有、它却没收到` | 脚本漏了那几个东西 | 在底下「说一句」里写清要点的那个（选择器 / 那段 HTML / 一句人话） |
| `这一版改了什么` 里只有空格/一处没改 | 这一版没真的改东西 | 「说一句」说清改哪儿，让它重出（它会重试） |
| `窗口没了` | 那个浏览器死了 | 按「重开窗口，接着走」（从停下的地方接着跑） |
| `停在 … 等你说` | 到闸了 | 看那一闸的事实，然后继续 / 说一句 |

---

## 6. 三条规矩

1. **它正在跑的时候，别去动那个窗口的鼠标键盘。** 两边一起动，动作会落到别处，
   而失败会被记成**脚本的问题**。想动手就等它停在闸上（那才是你的时刻）——
   而且你动过页面之后，用「说一句」告诉它，别让它自己猜。
2. 「**停下**」是撤不回的：停下了就是停下了（那一步不会做，页面与文件都保持原样）。
3. 自测那一关会往站方**真提交**（每趟最多 3 次）—— 别拿一个真在赚钱的站乱试。
