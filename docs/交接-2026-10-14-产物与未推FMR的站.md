**推的方法**（2026-10-14 用这条推的 foodandwine，两次回读比对过）：

```bash
# token 在 siteforge.env 的 FORM_SCRIPT_WRITE_TOKEN（不要打印它）
curl -sS -X POST https://fmr.3tkj.cn/api/quest/formScript/update \
  -H 'Content-Type: application/json' \
  -H "X-Api-Token: $FORM_SCRIPT_WRITE_TOKEN" \
  -d "$(python3 - <<'PY'
import json, pathlib
key = "chattyromance.com/land/sp/568ac9a2"     # ← 换站就换这一行
src = pathlib.Path("/company/siteforge/forms/sites/chattyromance.py").read_text()
print(json.dumps({"site": key, "source": src, "operator": "lcr"}))
PY
)"
```

- 正文**必须是 `application/json`**；三个字段 `site` / `source` / `operator` **必填**；
  鉴权在头 `X-Api-Token`（与配置那个写口是同一串 token）。
- **成功判据 = body 的 `status` 是 200**；回执的 `data.sha256` 是**写进去那份**的指纹 ——
  **拿它和你本地算的 sha 比一次**，再去读口回读比一次（两次都一致才叫写成了）。
- `data.created: true` = 后端**新建了一行**（这个站之前没有）；`false` = 换掉了原来那份。
- 键是 **host/path**（`agent/service._key_from_url`：去 scheme、去 query、去 fragment）。
  ⚠️ **一个站写两个键 = 后端两条行，生产按其中一个下载、可能拿到不是这一份**（静默）——
  拿不准就先 `POST /job/{id}/upload/prepare`（`{"operator":"…","force":true}`）问一次，
  **它绝不写**，只算键 + 读后端现值。
