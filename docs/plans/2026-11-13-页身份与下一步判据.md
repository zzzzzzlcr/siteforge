## Global Constraints

- **不许改 `_stable_url` 的输出。** 它进 `when.url_contains`；盘上已有产物按那个串重放。尾斜杠、query、host 大小写等只在**比较处**抹平。
- **不许改 `_exact_url` 的收紧语义。** `url_equals` 必须逐 path 比较；`/contact` 不许命中 `/contact/loved-one`，`/Products` 不许命中 `/products`。
- **只处理 `http` / `https`。** 其它 scheme（`about:`、`chrome:`、相对串）走原样逐字比较，不猜。
- **不引第三方依赖。** 只用标准库；本文件已有 `re` / `posixpath` / `urllib.parse`。
- **非 http(s) 或解析失败不许抛。** 一律退回旧的字面比较；`_exact_url` 退回旧的去 query/fragment/尾斜杠。
- **query 在身份比较里仍忽略。** `?step=1` 与 `?step=2` 视为同一文档；区分那一屏靠正文门（现有设计，`zekear` 那趟的口径）。这一条写进文档，不偷偷改。
- **`index.html` 与 `/` 仍是两页。** 服务器可能真的给两份内容；不猜。
- **path 大小写仍敏感。** 只归一 host；`/Products` 与 `/products` 是两条地址（RFC 语义，也是现有精确门的前提）。
- 现有回归必须保持绿：尾斜杠、bare-url、共享正文两页、往返不压平、轮换变体五族。

## Review Focus

- **`url_equals` 是落盘格式。** 旧产物里存的是旧 `_exact_url` 的输出（如 `https://Example.test/contact/`）；新比较必须让它们照旧命中，同时不许放过父子页。Task 2 的用例写死这两个方向。
- **`www` / http-https 等价会把「不同主机」认成一页。** 只在 host 逐字相同、path 逐字相同、路由相同的前提下等价；不同 host 仍必须分开。Task 1 的 #17 钉这条反例。
- **`path` 大小写与 `%2F` 是两个真会咬人的边界。** 小写整条 URL 会把 `/Products` 与 `/products` 并掉；把 `%2F` 解码成 `/` 会把一个段拆成两段。Task 1 两条反例。
- **hash 路由只解决「生成期判身份」，不解决重放。** `_stable_url` / `_exact_url` 仍丢 fragment；`#/step1` 与 `#/step2` 的重放区分仍然靠正文门。Task 4 必须钉「会报撞车」，而不是「悄悄当成一页」。
- **`ir._stable` 与生成侧原先不是同一条口径。** 它把整条 URL 小写、又不丢轮换末段；切到同一把尺子后，「同址几组」的计数会变。Task 3 两个方向各一条用例，防止把本来对的产物误拦。

## 一、页身份判据表（实现与用例的共同规格）

`_same_stable_url(a, b)` 对下表每一行给出**确定**答案。表外的形状按保守处理：拿不准 ⇒ 两页。

| # | 场景 | 例子 | 同一页？ | 规则 |
|---|---|---|---|---|
| 1 | 尾斜杠 | `/products` ↔ `/products/` | 是 | path 去尾斜杠后相等 |
| 2 | query / fragment 锚点 | `/p?utm=1#top` ↔ `/p` | 是 | 身份不看 query；`#top` 是页内锚点，丢 |
| 3 | scheme / host 大小写 | `HTTPS://Example.COM/p` ↔ `https://example.com/p` | 是 | scheme、host 小写；path 原样 |
| 4 | 默认端口 | `https://e.test:443/p` ↔ `https://e.test/p` | 是 | 80/443 视同缺省 |
| 5 | `www.` | `https://www.e.test/p` ↔ `https://e.test/p` | 是 | host 去 `www.` 后相等 |
| 6 | http ↔ https | `http://e.test/p` ↔ `https://e.test/p` | 是 | 视为同一站点的重定向变体 |
| 7 | 空 path | `https://e.test` ↔ `https://e.test/` | 是 | path 缺省为 `/` |
| 8 | 点段 | `/a/./b` ↔ `/a/b`；`/a/../b` ↔ `/b` | 是 | 按 URL 语义消点段 |
| 9 | 无保留字百分号编码 | `/%7Euser` ↔ `/~user`；`/%41` ↔ `/A` | 是 | 只解 `A-Za-z0-9-._~`，其余保留 |
| 10 | host 末尾点 | `e.test.` ↔ `e.test` | 是 | DNS 根点 |
| 11 | 轮换末段 | `/walk-in-showers/cr640` ↔ `/walk-in-showers/gt1791-1` | 是 | 两段以上且末段像 id ⇒ 比目录 |
| 12 | 父 / 子 path | `/funnel` ↔ `/funnel/step2`（含 `/funnel/`） | 否 | 短的不是长的路径前缀 |
| 13 | path 大小写 | `/Products` ↔ `/products` | 否 | path 逐字 |
| 14 | `index.html` ↔ 目录 | `/index.html` ↔ `/` | 否 | 服务器可能给两份 |
| 15 | 保留字编码 | `/a%2Fb` ↔ `/a/b` | 否 | `%2F` 不是分隔符 |
| 16 | hash 路由 | `/app#/step1` ↔ `/app#/step2` | 否 | `#/`、`#!/`、`#!` 是路由，不是锚点 |
| 17 | 不同 host | `a.test/p` ↔ `b.test/p` | 否 | host 必须相等 |

def _url_core(url: str) -> tuple[str, str, int | None, str, str] | None:

    非 http(s) 或解析失败返回 None（调用方退回字面比较，绝不抛）。
    """

    """同一页的比较键：host 去 `www.`、path 去尾斜杠、忽略 scheme 与 query。"""

def _stable_path(path: str) -> str:
    """按 _stable_url 的老口径取目录：末段像 id 才丢，否则整条 path。"""

- `_same_stable_url` 先比 `_page_key`；相等 ⇒ True。
- 不等时，只允许走「轮换变体」：host、port、route 相同；路径都无路由；`_stable_path` 相等；
  且**短的不是长的路径前缀**。
- 任一 `_page_key` 为 `None` ⇒ 退回现行字面比较
  `a.split("#")[0].split("?")[0].rstrip("/") == b...`，非空才算同一页。
- `_exact_url` 改成 `_url_core` 的**收紧**投影：保留 scheme、host（输出小写）、非默认端口、
  path 逐字（只去尾斜杠）；丢了 query / fragment；`#` 路由不投影（重放侧
  `template.py` 本就按去 fragment 的地址比）。解析失败退回现行实现。
- `ir._stable` 委托 `_page_key`，返回稳定的字符串；`None` 时退回原串。**不丢轮换末段**。

```python
import posixpath
from urllib.parse import urlsplit

_UNRESERVED = set("ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789-._~")

def _norm_pct(text: str) -> str:
    def one(m):
        ch = chr(int(m.group(1), 16))
        return ch if ch in _UNRESERVED else "%" + m.group(1).upper()
    return re.sub(r"%([0-9A-Fa-f]{2})", one, text)

def _url_core(url):
    raw = str(url or "").strip()
    route = ""
    if "#" in raw:
        raw, frag = raw.split("#", 1)
        if frag.startswith("/") or frag.startswith("!"):
            route = frag.rstrip("/") or "/"
    try:
        p = urlsplit(raw)
    except ValueError:
        return None
    scheme = p.scheme.lower()
    if scheme not in ("http", "https"):
        return None
    host = (p.hostname or "").lower().rstrip(".")
    if not host:
        return None
    try:
        port = p.port
    except ValueError:
        return None
    if (scheme == "http" and port == 80) or (scheme == "https" and port == 443):
        port = None
    path = _norm_pct(p.path or "/")
    if "//" not in path:                       # 空段可能有意义：有 `//` 就不折叠
        trail = path.endswith("/") and path != "/"
        path = posixpath.normpath(path)
        if not path.startswith("/"):
            path = "/" + path
        if trail and not path.endswith("/"):
            path += "/"
    return scheme, host, port, path, route

def _page_key(url):
    core = _url_core(url)
    if core is None:
        return None
    scheme, host, port, path, route = core
    if host.startswith("www."):
        host = host[4:]
    return host, port, path.rstrip("/"), route

def _stable_path(path: str) -> str:
    bare = (path or "/").rstrip("/")
    segs = [s for s in bare.split("/") if s]
    if len(segs) < 2 or not _id_like(segs[-1]):
        return bare
    return "/" + "/".join(segs[:-1])

def _same_stable_url(url: str, other: str) -> bool:
    one, two = _page_key(url), _page_key(other)
    if one is not None and two is not None:
        if one == two:
            return True
        if one[:2] != two[:2] or one[3] != two[3]:
            return False                       # host / port / 路由不一致
        if one[3] or two[3]:
            return False                       # 有路由时不走轮换变体
        a, b = one[2], two[2]
        if _stable_path(a) != _stable_path(b):
            return False
        return not (a.startswith(b + "/") or b.startswith(a + "/"))
    a = (url or "").split("#")[0].split("?")[0].rstrip("/")
    b = (other or "").split("#")[0].split("?")[0].rstrip("/")
    return bool(a) and a == b
```
